01누가 쓰나

제품 사용법을 확인하려는 사용자. 긴 매뉴얼에서 기능의 감독 요건·해제 방법·제한 사항의 정확한 문장을 찾아야 한다. 사용 빈도 실측은 기록 없음.

02지금은

매뉴얼을 열어 목차와 키워드 검색으로 관련 부분을 찾고 직접 읽는다. 현재 탐색 시간과 절감량은 기록 없음.

03없앨 동작 하나

질문의 답이 있는 문장을 긴 매뉴얼에서 수동으로 훑어 찾는 동작을 줄인다.

04핵심 기능 1개

TXT·Markdown 매뉴얼을 넣고 질문하면 Voyage AI 임베딩과 pgvector 검색으로 근거를 찾아 Claude가 출처 문장과 함께 답한다.

05안 만드는 것 3개

  • PDF OCR과 이미지 문서 해석
  • 로그인·팀 권한 관리
  • 웹 검색과 문서 밖 지식으로 답변 보충

06성공 판정

  • PDF 전체329쪽·937,449자·1,904청크의 실제 임베딩·저장과 두 세션 공유 조회를 확인했다. 전화기·타이어 라벨·해제 질문은 출처 문장과 함께 답했다. 없는 출시일 질문은 최초 번역 오류 수정 후 새 세션 재시도로 모른다고 답했다. 최종3+1 통과와 최초 실패를 구분하며 청킹한 글자 수와 이유를 설명한다.

07내 옵션 + 이유

정적 화면과 Node 서버리스 API, 기존 Supabase pgvector를 쓴다. Voyage AI 임베딩과 Claude 생성을 분리하고 600자·80자 겹침을 적용한다. 기본 자료는 Tesla Model 3(2024+) North America·Software 2026.38.3 PDF 전체 329쪽의 영문 추출 텍스트다. 미리 등록된 공용 매뉴얼과 내 매뉴얼을 구분한다. 원본 PDF 파일 공개와 그림 OCR은 지원하지 않는다.

08리스크 + 검증법

걱정되는 것: 관련성이 낮은 문서 조각으로 그럴듯한 답을 생성할 수 있다. 무료 토큰과 별개로 요청 속도 제한도 있다. 공개 배포 URL은 기록 없음.
화요일 스파이크로 확인: 이전 요약의 전화기 질문 실패는 전체 원문 적재 후 p.106/PDF108 기기 금지 인용 답변으로 해결했다. 타이어 라벨 p.204/PDF206으로 FSD 장 밖 검색도 확인했다. 없는 질문은 검색 번역 JSON 잘림을 보완한 뒤 새 세션 재시도로 모른다는 응답을 확인했다. 공개 배포는 하지 않았다.
