기본 자료는 'Tesla Model 3 사용 설명서' PDF 전체329쪽 영문 추출 텍스트다. 002 SQL을 적용하고 정규화937,449자·1,904청크의 실제 임베딩·DB exact count·ready를 확인했다. 두 세션에서 동일 공용 매뉴얼 메타데이터을 조회했고 전화기·타이어 라벨·해제 질문은 원문 근거로 답했다. 없는 출시일 질문은 최초 번역 오류 수정 후 새 세션에서 재시도해 모른다는 응답·인용0개를 확인했다. 최종3+1 통과이며 최초 시도 전체 성공은 아니다. 원본 PDF 파일 공개와 그림OCR은 지원하지 않는다. 공개 배포와 initialB 등록은 아직 남아 있다.

배포 후 사이트 루트 URL을 initialB에 등록한다. 소개 화면에서 `/docs/plan.html`과 `/docs/report.html`로 이동할 수 있어야 한다. 배포 URL이 확인되면 report.html의 `data-f="url"` href와 텍스트를 실제 주소로 바꾸고 제출 상태를 갱신한다.

등록 전 확인: 실제 공개 접근, 전체 PDF 텍스트의 사전 인덱싱 완료, 브라우저 간 중복 등록 없이 기본 자료 조회, 3+1 RAG 시연, 근거 문장·원문 차종·지역·버전·쪽수 표시, 텍스트 추출의 한계와 비밀키 미노출. 원본 PDF 파일은 공개하지 않는다. report.html의 레지스트리 복사는 7열, 비교표 복사는 11열이다. 공개 URL이 비어 있는 현재 상태에서는 복사 결과를 최종 제출하지 않는다.
