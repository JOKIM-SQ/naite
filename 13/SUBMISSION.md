## 제출물

- [ ] 공개 사이트 URL 확인
- [ ] `/docs/plan.html` 공개 접근 확인
- [ ] `/docs/report.html` 공개 접근 확인
- [ ] report의 실제 배포 URL 반영
- [ ] initialB에 사이트 URL 등록 (사용자가 등록)

## 기능 시연

- [ ] TXT/Markdown 매뉴얼 업로드와 인덱싱
- [ ] 실제 Voyage AI 임베딩 → Supabase pgvector 저장·검색
- [ ] 문서에 있는 질문 3개에 Claude 답변 + 정확한 출처 문장
- [ ] 문서에 없는 질문 1개에 모른다고 응답
- [ ] 청킹 크기·겹침·선택 이유 설명
- [ ] 출처 클릭으로 원문 확인

## 검증 자료

측정하지 않은 값과 외부 API 미실행은 `기록 없음`으로 둔다. 단위 테스트와 실제 API 호출, 브라우저 시연을 구분한다. 실제 시나리오별 질문·기대 근거·응답·판정·실행 시각을 기록하면 제출 시 재현이 쉽다.

| 종류 | 질문 | 기대 결과 | 실제 결과 |
|---|---|---|---|
| 있는 질문 1 | HEPA 필터는 언제 교체하고 물로 씻어도 되나요? | 6개월 권장 교체·물 세척 금지. §3 필터와 관리 원문 인용 | 기록 없음 |

## 3분 데모 순서

1. 가상 MORI Air Mini 매뉴얼임을 표시하고 문서를 준비한다.
2. 있는 질문 3개를 던져 답변과 근거 문장을 함께 보여준다.
3. 문서에 없는 질문을 던져 모른다는 응답을 확인한다.
4. 청킹한 글자 수·겹침 및 이유, 검색과 생성의 역할을 설명한다.

안 만든 것: PDF OCR, 로그인·팀 권한, 웹 검색. 별도 확장 기능은 추가하지 않는다.
