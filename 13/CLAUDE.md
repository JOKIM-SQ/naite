# S13 Folio · 폴리오

사용자 승인 범위: 가장 간단한 스택으로 제품 매뉴얼 Q&A를 구현하고 유려한 UI/UX, initialB 소개 화면과 제출 문서를 준비한다. 작업 범위는 `13/`다. 상위 문서의 S07 주제와 과거 요일별 구현 제한은 이번 S13 요청에 적용하지 않는다.

- 스택: 정적 HTML/CSS/JS + Node 서버리스 API + Supabase Postgres/pgvector + Voyage AI 임베딩 + Claude 답변. pgvector를 문자열 검색이나 하드코딩된 답변으로 대체하지 않는다.
- 핵심 흐름: TXT/Markdown 매뉴얼 → 청킹 → Voyage 임베딩 → pgvector 저장/검색 → Claude 근거 답변과 출처 문장. 문서에 없는 내용은 모른다고 답한다.
- 기본 자료는 '미리 등록된 매뉴얼'의 'Tesla Model 3 사용 설명서'다. 사용자 제공 Model 3(2024+) North America, Software 2026.38.3 PDF 전체 329쪽에서 추출한 영문 텍스트를 서버에서 한 번 임베딩해 공유한다. sample 또는 FSD 6쪽만을 전체 매뉴얼이라고 표시하지 않는다. 원본 PDF 파일 자체를 공개하지 않으며 그림·이미지 OCR은 지원하지 않는다. 미리 등록된 매뉴얼은 준비 완료 후 자동 선택하고 내 매뉴얼의 개인 문서와 구분한다. 원문 쪽수와 지역·버전을 표시하며 실제 차량 사용에는 최신 차량별 공식 지침이 우선한다.
- 비밀키는 서버 환경변수로만 읽고 출력·커밋·브라우저 전달하지 않는다. 사용자별 문서는 무작위 작업 공간 식별자로 분리한다.
- 테스트를 먼저 작성하고 실패를 확인한 뒤 구현한다. 타입 검사, lint, 테스트, build 및 실제 3+1 시나리오의 검증 범위를 구분해 기록한다. 미실행 API나 배포를 성공으로 기록하지 않는다.
- 모든 작업·검증·위임에서 gpt-6-astra를 사용하지 않는다. 기본 모델은 gpt-6.1-sol이다.
- `public/docs/plan.html`, `report.html`은 팀 템플릿의 구조·CSS·data-f·복사 스크립트를 보존한다. 미측정 값은 기록 없음. 공개 URL은 배포 후 실제 주소로 갱신한다.
- `13/`만 커밋하고 기존 루트 `.gitignore`와 `.omo/` 변경을 보존한다. 커밋 메시지는 한국어이며 본문에 `TODO: Phase X 완료`를 남긴다. 파일 편집은 apply_patch를 사용한다.
