01누가 쓰나

가격 변동이 잦은 Amazon 상품을 여러 개 저장해두고, 살 타이밍을 놓치지 않으려는 구매자. 하루에 제품 페이지를 여러 번 열어 현재 가격과 별점을 직접 비교한다.

02지금은

관심 상품을 브라우저 탭이나 장바구니에만 남겨 두고, 가격이 바뀌었는지 기억에 의존해 다시 확인한다. 이전 가격·별점과 비교할 기록이 없어 구매 시점을 판단하기 어렵다.

03없앨 동작 하나

상품 페이지를 매일 다시 열어 가격과 별점을 눈으로 확인하고 이전 값과 비교하는 동작.

04핵심 기능 1개

Amazon ASIN URL을 넣으면 상품을 영구 저장하고, Vercel Cron이 매일 가격과 별점을 수집해 누적 이력 그래프로 보여준다.

05안 만드는 것 3개

  • 목표 가격 도달 알림·이메일 발송
  • Amazon 외 쇼핑몰 가격 수집
  • 사용자 계정·개인별 공유 목록

06성공 판정

  • Amazon URL로 상품명·가격·별점·이미지·카테고리 태그를 저장할 수 있다.
  • 저장 상품을 새로고침 뒤에도 확인하고, 카드에서 S02식 계층 태그로 필터할 수 있다.
  • 가격·별점 지표와 기간을 전환해 실제 누적 이력을 확인할 수 있다.
  • 크론 수집 후 카드에 가격·별점 각각의 상승·동일·하락 상태가 표시된다.

07내 옵션 + 이유

Vercel Cron과 Supabase Postgres를 선택했다. 하루 한 번처럼 주기가 명확한 수집은 서버리스 크론으로 충분하고, 상품·계층 태그·일별 스냅샷의 관계 데이터는 Postgres에 영구 보관하기 적합하다. Amazon 응답이 불완전한 경우를 대비해 50회씩 두 번의 수집 사이클에서 값을 누적한다.

08리스크 + 검증법

걱정되는 것: Amazon HTML 응답이 간헐적으로 가격·별점·이미지·카테고리 일부를 누락할 수 있다.
검증: 누락 필드를 누적해 최대 두 번의 50회 수집을 수행하는 단위 테스트와 실제 URL 수집·크론 API를 확인한다.
