공식 TypeScript MCP SDK · 로컬 stdio

01프로젝트 준비

Node.js 환경에서 저장소를 내려받고 빌드합니다.

git clone -b codex/s12-weeknote-mcp \
  https://github.com/JOKIM-SQ/naite.git
cd naite/12
npm ci
npm run build

02MCP 클라이언트에 연결

클라이언트의 MCP 서버 설정에 아래 항목을 추가합니다.

{
  "mcpServers": {
    "weeknote": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/naite/12/dist/server.js"]
    }
  }
}

/ABSOLUTE/PATH는 내려받은 폴더의 실제 절대경로로 바꿔주세요.

읽는 범위도, 하는 일도 명확하게.

도구 하나, 출처 하나. 읽기 전용 get_assignment가 initialB 가이드만 조회합니다. 임의 URL이나 파일 경로는 입력받지 않습니다.

로컬에서 실행됩니다. MCP 클라이언트가 Node.js 프로세스를 stdio로 연결합니다. 이 웹사이트는 소개 페이지이며 도구를 실행하지 않습니다. 사이트 URL은 MCP 연결 주소가 아닙니다.
