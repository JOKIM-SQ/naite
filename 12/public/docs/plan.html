01누가 쓰나

initialB 주차 과제를 확인하는 John Kim. AI와 작업하면서 이번 주 미션·골·제약을 공식 가이드 기준으로 확인한다. 조회 빈도는 기록 없음이다.

02지금은

공식 가이드를 브라우저에서 열고 해당 주차를 찾아 AI 대화에 복사한다. 수작업 소요 시간은 기록 없음이다.

03없앨 동작 하나

AI에게 과제를 물을 때마다 공식 가이드의 해당 주차를 찾아 복사하는 동작을 줄인다.

04핵심 기능 1개

get_assignment({week: "s12"})를 호출하면 고정 공식 가이드를 읽고 해당 주차의 제목·미션·골·제약·출처·조회 시각을 반환한다.

05안 만드는 것 3개

  • 임의 URL·로컬 파일 조회와 쓰기 도구
  • DB·로그인·LLM 서버
  • 별도 채팅 UI

06성공 판정

  • Inspector CLI 2.13.0의 도구 목록·실제 S12 호출과 Claude Haiku 5.5 독립 세션의 동일 질문 비교를 확인했다. 연결 전 호출 0회에서 연결 후 get_assignment({week: "s12"}) 1회로 공식 과제·제약·제출 안내와 출처를 답했다. 새 SDK stdio 연결 초기화는 173ms 한 번의 관측이다. https://s12-weeknote.vercel.app/의 최초 공개 배포와 소개·두 문서의 비로그인 HTTP 200을 확인했다.

07내 옵션 + 이유

공식 TypeScript MCP SDK와 로컬 stdio를 선택했다. 읽기 전용 도구 1개·고정 데이터 소스 1개로 범위를 좁히고, 별도 인증·DB 없이 AI 클라이언트의 도구 연결을 확인한다. 서버 자체 API 키는 필요 없고 모델 접속은 클라이언트가 담당한다. 12/에서 npm ci → npm run build 후, MCP 클라이언트에 Node 실행 파일과 /ABSOLUTE/PATH/naite/12/dist/server.js를 stdio 명령으로 지정한다. 실제 경로로 바꿔야 한다. Inspector 2.13.0의 tools/list와 tools/call을 사용하며 정확한 명령은 저장소 README에 있다.

08리스크 + 검증법

걱정되는 것: 가이드 구조 변경이나 네트워크 오류로 잘못된 주차 내용이 전달되는 것.
화요일 스파이크로 확인: 고정 https://initialb.vercel.app/guide.html의 S12 실데이터와 파서 테스트를 비교하고, 실패를 성공 예시로 대체하지 않는지 확인한다. 출처·조회 시각·외부 원문 안내를 함께 반환한다.
