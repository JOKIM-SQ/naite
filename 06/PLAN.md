# S06 PRD — Review Radar Daily Tracker

| | |
|---|---|
| 스프린트 | S06 |
| 재사용 | S04 일별 가격·별점 스냅샷, S05 카드·분포 UI 패턴 |
| 데이터 | Supabase `weekly_projects` 스키마 |

## 핵심 기능

Amazon PDP URL을 추가하면 제품 카드가 생기고, 기준 가격·별점·즉시 노출된 상위 1~5개 리뷰를 저장한다. 매일 오전 6시(태평양 시간)에 활성 카드를 다시 확인해 가격·별점을 일별로 기록하고, 이전에 없던 리뷰 지문만 Claude에 보내 분석 결과를 누적한다.

카드를 누르면 장점·단점·페인 포인트 분포, 최근 일별 스냅샷, 누적 리뷰를 볼 수 있다. `/admin.html`에서 `ADMIN_PIN`으로 자동 추적을 켜거나 끈다.

## 성공 판정

- URL 하나로 Amazon 메타데이터와 첫 추적 카드가 저장된다.
- 날짜별 가격·별점·화면 리뷰 수가 하나의 스냅샷으로 누적된다.
- 리뷰 본문·제목·별점 지문으로 새 리뷰만 골라 Claude 분석 배치를 저장한다.
- 카드 상세에서 장점·단점·페인 포인트를 빈도순으로 보고, 원본 누적 리뷰와 일별 기록을 함께 본다.
- 자동 추적 OFF면 Vercel Cron이 Amazon·Claude 요청 전 중단된다.
- `ANTHROPIC_API_KEY`, Supabase 서비스 키, Cron 비밀값, 관리자 PIN은 브라우저에 노출되지 않는다.

## 배포 전 설정

1. 기존 Supabase 프로젝트 SQL Editor에서 `SUPABASE.sql`을 한 번 실행한다.
2. Vercel S06 프로젝트에 `.env.example`의 환경변수를 설정한다.
3. 배포 후 `vercel.json`의 13:00/14:00 UTC 크론 중 태평양 오전 6시에 해당하는 한 번만 실제 추적을 실행한다.

## 범위 밖

1. Amazon 전체 리뷰 목록·페이지네이션·필터 수집
2. 리뷰 원문 편집·공유·다운로드
3. 다중 조직·사용자 권한 관리
