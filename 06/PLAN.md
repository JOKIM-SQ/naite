# S06 PRD — Review Radar

| | |
|---|---|
| 스프린트 | S06 |
| 스택 카드 | Claude 호출 경로 |
| 내 옵션 | 서버리스 래핑 |

## 핵심 기능

리뷰 10~20개를 한 줄에 하나씩 붙여넣으면, 브라우저가 `/api/analyze` 서버 함수에만 요청하고 서버 함수가 Claude를 호출해 다섯 항목의 구조화된 분석을 화면에 표시한다.

## 성공 판정

- 리뷰 10개를 넣어 핵심 요약·긍정 요인·부정 요인·페인 포인트·다음 개선의 5개 항목이 화면에 나온다.
- 결과는 Claude가 반환한 JSON을 검증한 뒤에만 렌더링한다.
- 브라우저 코드와 네트워크 요청에 `ANTHROPIC_API_KEY`가 포함되지 않는다.
- 10개 미만 또는 20개 초과 입력은 Claude 호출 전에 막는다.

## 안 만드는 것

1. 로그인과 리뷰 저장 이력
2. 파일 업로드, 크롤링, 리뷰 수집
3. 결과 편집·공유·다운로드

## 리스크와 스파이크

`ANTHROPIC_API_KEY`가 아직 현재 로컬 환경에 없어서 실제 Claude 호출은 미실행이다. 서버 API는 요청 형식과 JSON 응답을 단위 테스트로 검증했으며, 키를 Vercel 환경변수에 추가한 뒤 10개 리뷰의 실제 응답을 확인한다.
