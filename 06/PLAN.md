# S06 PRD — Review Radar

| | |
|---|---|
| 스프린트 | S06 |
| 스택 카드 | Claude 호출 경로 |
| 내 옵션 | 서버리스 래핑 |

## 핵심 기능

Amazon PDP URL을 넣으면, 브라우저가 `/api/analyze` 서버 함수에만 요청하고 서버 함수가 PDP에 즉시 보이는 상위 1~5개 리뷰를 읽은 뒤 Claude로 다섯 항목의 구조화된 분석을 화면에 표시한다.

## 성공 판정

- Amazon PDP URL 하나를 넣어 핵심 요약·긍정 요인·부정 요인·페인 포인트·다음 개선의 5개 항목이 화면에 나온다.
- 페이지에 즉시 보이는 상위 리뷰 1~5개의 제목·본문·별점만 분석하고, 전체 리뷰 목록·페이지네이션은 읽지 않는다.
- 결과는 Claude가 반환한 JSON을 검증한 뒤에만 렌더링한다.
- 브라우저 코드와 네트워크 요청에 `ANTHROPIC_API_KEY`가 포함되지 않는다.
- 10개 미만 또는 20개 초과 입력은 Claude 호출 전에 막는다.

## 안 만드는 것

1. 전체 리뷰 목록·페이지네이션·필터 수집
2. 로그인과 분석 이력 저장
3. 결과 편집·공유·다운로드

## 리스크와 스파이크

Amazon은 요청을 차단할 수 있으므로, 차단 페이지와 즉시 노출된 리뷰 없음 상태를 명확히 안내한다. `ANTHROPIC_API_KEY`가 아직 현재 로컬 환경에 없어서 실제 Claude 호출은 미실행이다. 서버 API는 요청 형식과 JSON 응답을 단위 테스트로 검증했으며, 키를 Vercel 환경변수에 추가한 뒤 공개 리뷰가 보이는 PDP의 실제 응답을 확인한다.
