01누가 쓰나

Amazon 상품 상세 페이지를 보며 경쟁 제품 반응을 빠르게 읽는 3년차 프로덕트 매니저. 첫 화면에 보이는 리뷰에서 반복되는 불만과 개선 우선순위를 잡아야 한다.

02지금은

Amazon PDP를 열고 첫 화면의 리뷰 제목·본문·별점을 읽으며 메모 앱에 긍정·부정 의견을 손으로 옮긴다.

03없앨 동작 하나

Amazon PDP에 즉시 보이는 상위 리뷰를 읽고 반복되는 긍정 요인과 페인 포인트를 수동으로 묶는 동작.

04핵심 기능 1개

Amazon PDP URL을 넣으면 상위 1~5개 리뷰를 읽고 Claude가 JSON으로 분석해 다섯 줄의 요약으로 화면에 표시한다.

05안 만드는 것 3개

  • 전체 리뷰 목록·페이지네이션·필터 수집
  • 로그인과 분석 이력 저장
  • 결과 편집·공유·다운로드

06성공 판정

  • Amazon PDP URL을 넣으면 상위 1~5개 리뷰로 만든 다섯 항목의 분석 결과가 JSON을 거쳐 화면에 보이고, API 키는 브라우저에 노출되지 않는다.

07내 옵션 + 이유

브라우저가 API 키를 절대 갖지 않도록 Claude 호출을 Vercel 서버 함수 뒤에 둔다. 모델 호출 코드는 한 곳에 두고, 프런트엔드는 입력과 결과 표시만 맡는다.

08리스크 + 검증법

걱정되는 것: Amazon이 차단 페이지를 반환하거나, Claude가 JSON 외 텍스트를 섞어 반환하는 것.
화요일 스파이크로 확인: 서버 함수의 차단 감지·리뷰 파서·JSON 파서·요청 헤더를 테스트하고, 환경변수 설정 뒤 공개 리뷰가 보이는 PDP의 실제 호출을 확인한다.
