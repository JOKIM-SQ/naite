01누가 쓰나

Amazon 상품 상세 페이지를 보며 경쟁 제품 반응을 빠르게 읽는 프로덕트 매니저. 공개 리뷰에서 반복되는 불만과 개선 우선순위를 잡아야 한다.

02지금은

Amazon PDP를 열고 리뷰 제목·본문·별점을 읽으며, 신규 반응과 별점 변화를 스프레드시트에 손으로 옮긴다.

03없앨 동작 하나

Amazon PDP의 공개 리뷰를 읽고 반복되는 긍정·부정 요인과 페인포인트를 수동으로 묶고, 다음 날 변화를 다시 확인하는 동작.

04핵심 기능 1개

Amazon PDP URL을 넣으면 렌더링된 공개 리뷰를 수집하고, Claude가 구조화 JSON으로 긍정·부정 요인과 페인포인트를 분석해 일일 변화 신호로 표시한다.

05안 만드는 것 3개

  • Amazon 전체 리뷰 목록·페이지네이션·필터 수집
  • 리뷰 분석 결과의 수동 편집·공유·다운로드
  • 개인화 알림과 경쟁 상품 자동 추천

06성공 판정

  • Amazon PDP URL을 넣으면 공개 리뷰 분석 결과가 구조화 JSON을 거쳐 화면에 보이고, API 키는 브라우저와 네트워크 응답에 노출되지 않는다.

07내 옵션 + 이유

브라우저가 API 키를 절대 갖지 않도록 Claude 호출을 Vercel 서버 함수 뒤에 둔다. Browserbase로 렌더링한 PDP 데이터와 분석 요청을 서버에서만 처리하고, 프런트엔드는 결과 표시만 맡는다.

08리스크 + 검증법

걱정되는 것: Amazon이 차단 페이지를 반환하거나, Claude가 JSON 외 텍스트를 섞어 반환하는 것.
검증: Browserbase 렌더링 경로와 다회 수집을 적용하고, 서버 함수의 차단 감지·리뷰 파서·JSON 정규화 테스트와 실제 PDP 호출을 확인한다.
