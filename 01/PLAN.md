## 01 누가 쓰나

iBD 주간 MVP 훈련에 참가하는 팀원 **3~5명**. 주 1회, 금요일 데모데이 전에 자기 결과물을 제출한다.
한 사람이 시즌(18주) 동안 18번 제출하므로 팀 전체로는 **54~90장**의 카드가 쌓인다.

## 02 지금은

**제출을 받을 곳이 아직 없다.** 그래서 1주차의 결과물이 곧 그 제출 창구(갤러리 대시보드)다.
갤러리가 없으면 시트에 열 7개(스프린트·제목·만든 사람·스택 카드·옵션·URL·소개)를 손으로 채워야 하고,
문서 링크는 매번 `URL + /docs/plan.html` 로 손으로 조립해야 한다.

## 03 없앨 동작 하나

**시트에 열 7개를 손으로 채우는 것.** URL 하나 드랍(5초) 으로 대체한다 — 나머지 6개 열은 서버 함수가 `/docs/plan.html` 에서 읽어 채운다.

## 04 핵심 기능 1개

배포 URL 을 드랍하면 그 사이트의 `/docs/plan.html` 을 서버 함수가 읽어
카드 메타(제목·만든 사람·스택·소개·소스)를 자동으로 채우고 스크린샷을 1회 찍어 저장한다.

## 05 안 만드는 것 3개

1. **필터 심화** — 스택 칩 토글 하나만. 복합 조건·정렬 옵션·검색 결합은 다음 갤러리 버전
2. **검색** — 시즌이 다 차도 100장 남짓, 스크롤 + 스프린트 점프로 충분
3. **수정·삭제 UI** — 로그인 없는 사이트에 삭제 버튼은 무방비. 잘못 드랍하면 관리자가 DB 에서 지운다 (25.08.02 결정 확정)

## 06 성공 판정

- URL 을 드랍하면 **다른 사람 브라우저에서도** 카드가 보인다 (새로고침에 카드가 늘어난다)
- 규약 준수 사이트는 제목·만든 사람·소스가 자동으로 채워지고, 드랍 시 스크린샷 썸네일이 붙는다
- 규약 미준수 URL 은 도메인 카드로 폴백 — **드랍 실패는 없다**
- 카드가 Supabase 에서 나온다 (하드코딩 아님)
- 배포 후 `dropboard-pi.vercel.app/docs/plan.html` 이 열린다 (셀프 드랍으로 자기 규약 검증)

## 07 내 옵션 + 이유

**Vercel Pro 를 이미 구독 중이고, 붙이는 데 손이 가장 덜 가는 플랫폼이라서** 골랐다.
깃 연결 → Root Directory 를 `01` 로 지정 → 끝. 빌드 설정이 없고, `api/drop.js` 를 파일 하나 두는 것만으로 서버 함수가 된다.
1주차 결과물이 시즌 인프라가 되는 주라 **호스팅 자체에 시간을 쓰지 않는 것**이 선택 기준이었다.

18주를 레포 하나에 담는다는 점도 이 선택을 뒷받침한다 — **Cloudflare Pages 는 레포당 프로젝트 5개**라
한 호스트에 몰면 6주차에 막힌다. Pro 구독이라 Hobby 상한(25개) 도 걸리지 않는다.

## 08 리스크 + 검증법

**걱정되는 것 (1) — 정적 파일 경로.** 규약은 `public/docs/plan.html` 인데
Vercel zero-config 는 프레임워크가 없을 때 Root Directory 를 그대로 서빙할 수도, `public/` 을 output 으로 잡을 수도 있다.
후자가 아니면 배포 URL 이 `/public/docs/plan.html` 이 되어 **규약을 내가 먼저 깬다.**

> 화요일 스파이크로 확인: `01/` 을 Root Directory 로 붙여 배포하고
> `dropboard-pi.vercel.app/docs/plan.html` 을 직접 열어본다. 안 열리면 `01/docs/` 로 옮긴다.

**걱정되는 것 (2) — 스크린샷.** 서버 함수 안에서 헤드리스 브라우저를 띄우는 건
Vercel 함수 실행 시간·번들 크기 제한에 걸릴 수 있다.

> 화요일 스파이크로 확인: 외부 스크린샷 API 1회 호출 → Supabase `shots` 버킷 업로드까지 되는지만 본다. 안 되면 썸네일 없이 도메인 카드로 폴백.

**걱정되는 것 (3) — 빌드 경로 필터.** 안 걸면 어느 파일을 고쳐도 연결된 프로젝트 전부가 재빌드된다.

> Vercel Settings → Git → Ignored Build Step 에 `git diff --quiet HEAD^ HEAD -- .`
