# S09 Chroma

현재 과제: 컬러 트렌드 무드보드. Google 로그인 후 모든 로그인 사용자가 같은 카드를 보고 추가·편집·삭제하는 공유 보드다. Color Thief로 대표색을 추출하고 Supabase Auth·Postgres·Storage에 저장한다. IndexedDB는 기존 브라우저 카드의 명시적 가져오기와 원본 보존에 사용한다.

사용자 확정: 이미지 한 번 드롭 후 대표색 5개와 원본 색상 수를 제한하지 않는 픽셀아트를 함께 생성한다. 모바일 대응은 제외한다. 세부 범위와 검증 기준은 PLAN.md, 모듈 계약은 CONTRACT.md를 따른다.

품질 개선 이력: 원본 색 유지 모드를 보존하고, 잔질감을 정리하는 독립 32색 픽셀 스타일 모드를 추가했다. 당시 기본은 스타일이었으며 아래 최신 승인에서 세밀 96칸으로 바뀌었다. 기존 모드 없는 카드는 원본으로 복원한다. 픽셀 보기에서 전체 이미지를 표시하고 정수 배율 PNG로 내보낸다.

최신 승인: 실제 벚꽃 사진 비교의 ‘세밀한 풍경’을 선택했다. 새 업로드 기본을 세밀(detail) 96칸으로 변경한다. PixelOE 얇은 윤곽·색 보정과 독립 Lab 최대 64색을 워커에서 처리한다. 브라우저 타일 양자화의 근사 차이는 문서화한다. 기존 스타일·원본 카드의 PNG는 자동 재생성하지 않는다.

게시 준비 승인: 메인 그래픽의 반복 애니메이션·정돈된 프레임, 공개 이미지 주소 입력·드롭을 지원한다. URL은 브라우저 CORS를 따르고 차단 시 파일 업로드로 안내한다. 서버 프록시·검색·AI 생성은 제외한다. 공개 앱과 규약 경로의 기획서·리포트, S09 원격 소스 링크를 준비하고 initialB의 실제 등록은 사용자가 URL을 드롭한다.

기획서·리포트는 `_template/public/docs/`를 복사해 CSS·data-f를 보존한다. 저장·복사·변환·다운로드를 실제 브라우저에서 검증하고 관찰하지 않은 결과는 기록 없음으로 남긴다.

최신 공유 보드 승인: Google PKCE 로그인이 필수다. 비로그인 상태는 로그인 안내가 있는 hero만 표시하며 업로드·URL 입력·보드와 로컬 카드 앱을 초기화하거나 조회하지 않는다. 설정 누락·연결 실패에도 게스트 보드로 우회하지 않는다. 로그인 후 `s09_cards` 전체를 복원하고 모든 인증 계정이 추가·편집·삭제한다. 별도 초대 멤버 기능과 실시간 자동 갱신은 없으며 다른 사용자의 변경은 새로고침으로 확인한다.

공유 저장 계약: `s09_cards.user_id`는 최초 등록자로 보존한다. 비공개 `s09-chroma-images`의 `creator/card/version/source|thumbnail|pixel` 경로는 다른 사용자가 편집해도 최초 등록자 prefix를 유지한다. 인증 사용자는 공유 읽기·수정·삭제, 신규 등록은 본인 등록자만 허용하며 직접 등록자 변경과 익명 접근은 거절한다. `SUPABASE.sql`은 기존 `s09_owner` 등 정책을 ALTER POLICY로 갱신하며 데이터를 삭제하지 않는다. 저장 revision CAS와 삭제 직렬 트랜잭션과 이미지 정리 대기열 재시도는 유지한다. 브라우저 카드는 명시적 가져오기로 복사하고 원본을 보존한다. `SUPABASE_URL`·`SUPABASE_PUBLISHABLE_KEY`만 앱에 제공하고 service_role는 넣지 않는다.

이미지 정리 대기열은 편집·삭제 실행자 계정에 귀속되며 그 계정의 목록 조회·저장·삭제 때만 재시도한다. hero와 제출용 공개 문서는 로그인 없이 열리며 앱 작업 영역에만 로그인을 요구한다. 계정별 개인 보드 격리는 제공하지 않는다.

검증 구분: 125/125개 테스트·타입·린트·빌드, 독립 리뷰 CLEAR/APPROVE, 운영 SDK 두 계정 9개 검사와 브라우저 개인/게스트 보드 분리는 이전 개인 보드 버전의 기록이다. 현재 공유 보드는 자동 테스트 134/134개·타입·린트·빌드를 통과했고 로컬 비로그인 화면의 로그인 버튼 2개·업로드와 보드 숨김을 확인했다. 운영 SQL을 트랜잭션으로 적용하고 실제 SDK 두 계정의 동일 카드·원본 바이트 복원, 타계정 이름/픽셀 수정·삭제, 최초 등록자 보존·변조 거절, 오래된 저장 CAS 거절, 익명 DB·Storage·RPC 차단, 무관한 타계정 경로 업로드 거절과 정리 대기열 0개를 확인했다. 독립 리뷰는 CLEAR/APPROVE이며 초기 로딩·로그아웃 경합 재현 1/1과 관련 테스트 34/34도 통과했다. 공개 배포와 공개 브라우저 QA는 확인 전이다. 실제 Google 계정 승인 전체 왕복도 미실시다. 최신 결과와 한계는 SPIKE.md에 별도로 기록한다.

현재 제외 범위: 이미지 검색·AI 생성·CORS 우회 서버 / 초대·권한 관리·실시간 동기화 / 모바일 전용 UI. 실제 갤러리 등록은 실행하지 않는다.

코드 변경 전 테스트 실패를 확인한다. 한국어 커밋과 `TODO: Phase X 완료` 본문을 사용한다. 다른 주차와 루트 .gitignore의 기존 수정은 포함하거나 되돌리지 않는다.
