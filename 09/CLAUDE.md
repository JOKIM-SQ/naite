# S09 Chroma

현재 과제: 컬러 트렌드 무드보드. Color Thief + IndexedDB를 게스트 처리 경로에, Supabase Auth·Postgres·Storage를 Google 로그인 후 개인 보드에 사용한다.

사용자 확정: 이미지 한 번 드롭 후 대표색 5개와 원본 색상 수를 제한하지 않는 픽셀아트를 함께 생성한다. 모바일 대응은 제외한다. 세부 범위와 검증 기준은 PLAN.md, 모듈 계약은 CONTRACT.md를 따른다.

품질 개선 이력: 원본 색 유지 모드를 보존하고, 잔질감을 정리하는 독립 32색 픽셀 스타일 모드를 추가했다. 당시 기본은 스타일이었으며 아래 최신 승인에서 세밀 96칸으로 바뀌었다. 기존 모드 없는 카드는 원본으로 복원한다. 픽셀 보기에서 전체 이미지를 표시하고 정수 배율 PNG로 내보낸다.

최신 승인: 실제 벚꽃 사진 비교의 ‘세밀한 풍경’을 선택했다. 새 업로드 기본을 세밀(detail) 96칸으로 변경한다. PixelOE 얇은 윤곽·색 보정과 독립 Lab 최대 64색을 워커에서 처리한다. 브라우저 타일 양자화의 근사 차이는 문서화한다. 기존 스타일·원본 카드의 PNG는 자동 재생성하지 않는다.

게시 준비 승인: 메인 그래픽의 반복 애니메이션·정돈된 프레임, 공개 이미지 주소 입력·드롭을 지원한다. URL은 브라우저 CORS를 따르고 차단 시 파일 업로드로 안내한다. 서버 프록시·검색·AI 생성은 제외한다. 공개 앱과 규약 경로의 기획서·리포트, S09 원격 소스 링크를 준비하고 initialB의 실제 등록은 사용자가 URL을 드롭한다.

기획서·리포트는 `_template/public/docs/`를 복사해 CSS·data-f를 보존한다. 저장·복사·변환·다운로드를 실제 브라우저에서 검증하고 관찰하지 않은 결과는 기록 없음으로 남긴다.

개인 보드 승인: Google PKCE 로그인, 계정별 `s09_cards`와 비공개 `s09-chroma-images`, RLS를 사용한다. 게스트 IndexedDB 카드는 명시적 가져오기로 복사하며 브라우저 원본을 보존한다. 여러 탭의 오래된 저장은 revision CAS로 거절한다. 삭제·교체된 파일은 DB의 정리 대기열에 남겨 재시도한다. 카드에서도 바로 삭제 확인을 열 수 있다. `SUPABASE.sql`과 `SUPABASE_URL`·`SUPABASE_PUBLISHABLE_KEY`로 설정하며 service_role는 앱에 넣지 않는다.

최종 검증: 자동 테스트 125/125, 타입·린트·빌드 통과, 독립 리뷰 CLEAR/APPROVE·미해결 P1/P2 없음. 운영 Supabase 두 검증 계정의 실제 SDK 9개 검사와 테스트 인증 세션을 사용한 로컬·공개 브라우저 가져오기·저장·삭제·로그아웃 보드 분리를 확인했다. Google 화면 진입·복귀 주소는 확인했지만 실제 Google 계정 승인 전체 왕복은 미실시다. 자세한 수치와 한계는 SPIKE.md를 따른다.

현재 제외 범위: 이미지 검색·AI 생성·CORS 우회 서버 / 팀 공유 보드·실시간 동기화 / 모바일 전용 UI. 실제 갤러리 등록은 실행하지 않는다.

코드 변경 전 테스트 실패를 확인한다. 한국어 커밋과 `TODO: Phase X 완료` 본문을 사용한다. 다른 주차와 루트 .gitignore의 기존 수정은 포함하거나 되돌리지 않는다.
