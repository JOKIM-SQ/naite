# S09 Chroma

현재 과제: 컬러 트렌드 무드보드. Color Thief + IndexedDB를 실제 처리 경로에 사용한다.

사용자 확정: 이미지 한 번 드롭 후 대표색 5개와 원본 색상 수를 제한하지 않는 픽셀아트를 함께 생성한다. 모바일 대응은 제외한다. 세부 범위와 검증 기준은 PLAN.md, 모듈 계약은 CONTRACT.md를 따른다.

품질 개선 승인: 원본 색 유지 모드는 보존하고, 잔질감을 정리하는 독립 32색 픽셀 스타일 모드를 추가한다. 새 업로드 기본은 스타일이며 기존 모드 없는 카드는 원본으로 복원한다. 픽셀 보기에서 전체 이미지를 표시하고 정수 배율 PNG로 내보낸다.

기획서·리포트는 `_template/public/docs/`를 복사해 CSS·data-f를 보존한다. 저장·복사·변환·다운로드를 실제 브라우저에서 검증하고 관찰하지 않은 결과는 기록 없음으로 남긴다.

코드 변경 전 테스트 실패를 확인한다. 한국어 커밋과 `TODO: Phase X 완료` 본문을 사용한다. 다른 주차와 루트 .gitignore의 기존 수정은 포함하거나 되돌리지 않는다.
