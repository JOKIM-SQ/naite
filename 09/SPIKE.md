## 사용자 동작과 실패 경로

- 카드 원본/픽셀 탭과 상세 미리보기에서 실제 이미지 전환 확인. 1440px 화면에서 가로 넘침 없음.
- 이름을 `사진 테스트`로 변경한 뒤 곧바로 픽셀 탭 전환·32칸 변경. 이름과 설정 모두 유지됨.
- 새로고침과 같은 주소의 새 탭에서 원본 Blob·이름·32칸 설정·팔레트 복원 확인.
- 자동화 브라우저에서 `navigator.clipboard.writeText` 권한이 거부됨. 성공으로 표시하지 않고 모달 내부에 선택 가능한 HEX 입력 표시. `Meta+C` 후 이름 입력에서 `Meta+V`로 `#B6AD96`이 붙여넣어짐. 이 환경에서 클릭 한 번의 자동 복사 성공은 확인하지 못했음.
- 삭제 취소 후 카드 3개 유지. 검증용 카드 삭제 확정·새로고침 후 카드 2개 유지. 사용자 원본 파일은 삭제하지 않음.
- 실제 Drop 이벤트와 File·DataTransfer로 아래 파일을 처리했고 실패 카드가 늘지 않음을 확인.

## 자동 검사와 리뷰

- `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build` 통과.
- 자동 테스트 24개: 원본 RGBA 샘플링, 격자 비율, 5색 규약, 입력·디코딩 오류, IndexedDB transaction abort·복원, 컨트롤러 저장·다운로드·삭제·클립보드 실패·지연 작업 경합, 개발 서버 경로 제한.
