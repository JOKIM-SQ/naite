한 줄 결론

Color Thief로 대표색 5개를 추출하고 게스트는 IndexedDB에 보관한다. Google PKCE 로그인 후에는 Supabase Auth·Postgres s09_cards·비공개 Storage s09-chroma-images로 개인 보드를 제공하며 계정별 RLS를 적용한다. 브라우저 카드는 명시적 가져오기로 복사하고 원본을 보존한다. 여러 탭의 오래된 저장은 revision CAS로 거절하며 삭제·교체 파일은 DB 정리 대기열에서 재시도한다. 카드의 휴지통과 상세는 같은 삭제 확인 경로를 사용한다. 설정은 SUPABASE.sql과 SUPABASE_URL·SUPABASE_PUBLISHABLE_KEY를 사용하며 service_role는 앱에 넣지 않는다. 최종 125/125개 자동 테스트·타입·린트·빌드와 독립 리뷰 CLEAR/APPROVE를 통과했고 미해결 P1/P2가 없다. 운영 SDK 두 계정의 9개 검사로 바이트 복원, 타계정·익명 차단, 오래된 수정·삭제 후 재생성 거절, 파일 3개 삭제·대기열 0개를 확인했다. 실제 브라우저에서 7개 가져오기와 원본 보존, 공개 계정 보드 8개·편집 이름 복원, 픽셀 스타일 96칸·78,077 bytes PNG·새로고침 유지, 삭제 취소 8개/확정 7개와 로그아웃 후 게스트 보드 복귀를 확인했다. 로그인 후 검증은 테스트 인증 세션을 사용했다. Google 화면 진입과 공개 복귀 주소는 확인했지만 실제 Google 계정 승인 전체 왕복은 미실시다. 세밀 96칸·독립 Lab 최대 64색, 원본 색 유지·32색 스타일을 제공한다. 팀 공유·실시간 동기화, 이미지 검색·AI 생성·CORS 우회 서버, 모바일 전용 UI는 제외한다. 첫 저장 6분·벚꽃 로컬 변환 약 4.45초와 과거 91개 테스트·배포 0.79분·로딩 0.645초는 이전 게스트 게시 기록이다. 이번 배포·로딩 시간, 실제 월 비용과 3분 시연 리허설은 기록 없음. 상세 근거와 검증 한계는 SPIKE.md에 기록한다.
