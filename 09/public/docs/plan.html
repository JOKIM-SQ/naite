02지금은

이미지를 열어 색을 하나씩 고르고, 별도 도구에서 픽셀 효과를 만든다. 현재 소요 시간은 기록 없음.

03없앨 동작 하나

같은 이미지를 색 추출 도구와 픽셀 변환 도구에 각각 다시 올리는 동작.

04핵심 기능 1개

파일 또는 공개 이미지 주소를 넣으면 대표색 5개와 독립적인 픽셀아트를 자동 생성해 하나의 카드로 저장한다. 색을 클릭해 HEX를 복사하거나 변환 PNG를 내려받는다.

  • 로그인·클라우드 동기화
  • 이미지 검색·AI 이미지 생성·CORS 우회 서버
  • 모바일 전용 UI

06성공 판정

  • 실제 이미지에서 팔레트 5칸과 픽셀아트를 생성하고, 새로고침 후 카드와 설정을 복원한다. HEX 복사·PNG 다운로드·픽셀 크기 및 표현 모드 변경을 보여준다.

07내 옵션 + 이유

Color Thief는 원본에서 대표색 5개를 추출하고 IndexedDB는 이미지 Blob과 설정을 저장한다. 세밀 모드는 OpenCV.js 워커의 얇은 윤곽·색 보정 후 독립적인 Lab 최대 64색으로 만든다. 새 사진은 96칸이 기본이며, 원본 RGBA 샘플링과 기존 32색 스타일도 선택할 수 있다. Python 비교판의 타일 처리는 브라우저 RGB 2-means로 대체해 일부 픽셀 차이가 있다.

08리스크 + 검증법

걱정되는 것: 큰 이미지·브라우저 저장 실패·이미지 주소의 CORS 차단.
검증: 실제 파일과 공개 이미지 주소로 추출·변환·복원을 확인한다. 접근이 차단된 주소는 원본 파일 업로드로 안내한다. 12MB·15초 다운로드 제한과 저장 실패 시 기존 이미지를 보존하는지 검사한다.
