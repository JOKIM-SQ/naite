01누가 쓰나

사진과 이미지에서 디자인 색감을 찾고, 픽셀아트로 장면을 남기려는 사람.

02지금은

이미지를 열어 색을 하나씩 고르고, 별도 도구에서 픽셀 효과를 만든다. 현재 소요 시간은 기록 없음.

03없앨 동작 하나

같은 이미지를 색 추출 도구와 픽셀 변환 도구에 각각 다시 올리는 동작.

04핵심 기능 1개

이미지를 드롭하면 대표색 5개와 독립적인 픽셀아트를 자동 생성해 하나의 카드로 저장하고, 색을 클릭해 HEX를 복사하거나 변환 PNG를 내려받는다.

05안 만드는 것 3개

  • 로그인·클라우드 동기화
  • 외부 이미지 URL 수집·AI 이미지 생성
  • 모바일 전용 UI

06성공 판정

  • 실제 이미지에서 팔레트 5칸과 픽셀아트를 생성하고, 새로고침 후 카드와 설정을 복원한다. HEX 복사·PNG 다운로드·픽셀 크기 변경을 보여준다.

07내 옵션 + 이유

Color Thief는 이미지에서 실제 대표색을 추출한다. IndexedDB는 이미지 Blob과 팔레트를 함께 저장한다. Canvas의 원본 픽셀 샘플링은 대표색 추출과 독립적으로 실행해 픽셀아트 색상 수를 제한하지 않는다.

08리스크 + 검증법

걱정되는 것: 큰 이미지 처리와 브라우저 저장 실패, 팔레트 추출색이 적은 이미지.
화요일 스파이크로 확인: 실제 사진과 다색·단색·투명 이미지로 추출과 변환을 비교한다. 저장 트랜잭션 실패를 완료로 표시하지 않는지, 새로고침 복원과 PNG 출력을 확인한다.
