01누가 쓰나

사진과 이미지에서 디자인 색감을 찾고, 픽셀아트로 장면을 남기려는 사람.

02지금은

이미지를 열어 색을 하나씩 고르고, 별도 도구에서 픽셀 효과를 만든다. 현재 소요 시간은 기록 없음.

03없앨 동작 하나

같은 이미지를 색 추출 도구와 픽셀 변환 도구에 각각 다시 올리는 동작.

04핵심 기능 1개

파일 또는 공개 이미지 주소를 넣으면 대표색 5개와 독립적인 픽셀아트를 자동 생성해 하나의 카드로 저장한다. 게스트는 브라우저에 보관하고 Google 로그인 후에는 개인 보드를 사용한다. 기존 브라우저 카드는 가져오기를 눌러 복사한다. HEX 복사·PNG 저장과 카드에서 바로 삭제 확인도 지원한다.

05안 만드는 것 3개

  • 이미지 검색·AI 이미지 생성·CORS 우회 서버
  • 팀 공유 보드·실시간 동기화
  • 모바일 전용 UI

06성공 판정

  • 실제 이미지에서 팔레트 5칸과 픽셀아트를 생성하고, 게스트·로그인 보드를 각각 복원한다. 125개 자동 테스트와 운영 SDK 두 계정의 9개 검사를 통과했다. 실제 브라우저에서 7개 명시적 가져오기·원본 보존, 계정 보드 8개 복원·설정/PNG 유지, 삭제 취소·확정 8→7과 로그아웃 후 게스트 복귀를 확인했다.

07내 옵션 + 이유

Color Thief는 대표색 5개를 추출하고 IndexedDB는 게스트 이미지와 설정을 저장한다. Google 로그인은 Supabase Auth, 개인 카드 메타데이터는 Postgres s09_cards, 이미지는 비공개 Storage s09-chroma-images를 사용하며 계정별 RLS를 적용한다. 브라우저 카드 가져오기는 원본을 보존한다. 세밀 96칸은 OpenCV.js 워커에서 얇은 윤곽·색 보정과 독립 Lab 최대 64색으로 만든다. 원본 RGBA와 32색 스타일도 선택하며 Python 타일 처리와 일부 픽셀 차이가 있다.

08리스크 + 검증법

걱정되는 것: 저장 실패·계정 간 접근·여러 탭의 덮어쓰기·이미지 주소의 CORS 차단.
검증: 운영 RLS의 타계정·익명 차단, revision CAS 충돌과 삭제 후 재생성 거절, 이미지 3개 삭제·정리 대기열 0개를 확인했다. 타입·린트·빌드 통과 및 독립 리뷰 CLEAR/APPROVE다. 브라우저 로그인 후 검증은 테스트 인증 세션을 사용했다. Google 화면 진입·공개 복귀 주소는 확인했지만 실제 Google 계정 승인 전체 왕복은 미실시다. CORS 차단은 파일 업로드로 안내한다.
