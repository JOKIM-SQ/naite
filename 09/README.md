# Chroma — 색으로 모으는 영감

S09 컬러 트렌드 무드보드. Google 로그인 후 파일이나 공개 이미지 주소를 넣으면 대표색 다섯 개와 픽셀아트를 함께 생성합니다. 모든 로그인 사용자가 같은 Supabase 공유 보드의 카드를 보고 추가·편집·삭제합니다. 세밀·픽셀 스타일·원본 색 유지 중에서 선택할 수 있습니다. 새 사진은 세밀 96칸으로 만듭니다.

## 실행

Node.js 22 이상에서 `09` 디렉터리를 기준으로 실행합니다.

```sh
npm ci
npm run dev
```

로컬 주소: [http://127.0.0.1:3090/](http://127.0.0.1:3090/)

```sh
npx tsc --noEmit
npm run lint
npm test
npm run build
```

빌드와 개발 시작 시 Color Thief 3.5.0, OpenCV.js 5.0.0과 Supabase 클라이언트의 브라우저 모듈을 `public/vendor`에 준비합니다. 생성한 vendor 파일과 node_modules는 Git에 포함하지 않습니다. 앱 사용에는 아래 Supabase 설정과 Google 로그인이 필요합니다. 약 12.3MB의 OpenCV 런타임은 세밀 변환 때만 불러와 Web Worker에서 실행하고, 변환 완료·실패·시간 초과 시 워커를 해제합니다.

### Google 로그인과 공유 보드 설정

1. Supabase SQL Editor에서 이 디렉터리의 `SUPABASE.sql`을 관리자 권한으로 실행합니다. S09 전용 테이블·RPC·공유 RLS와 비공개 `s09-chroma-images` 버킷을 구성합니다. 기존 개인 보드의 `s09_owner` 등 정책은 ALTER POLICY로 갱신하며 기존 행·이미지는 삭제하지 않습니다. 현재 공유 정책의 운영 적용 여부는 아래 검증 현황과 `SPIKE.md`를 확인합니다.
2. 개발 서버 또는 Vercel 환경에 `SUPABASE_URL`과 `SUPABASE_PUBLISHABLE_KEY`를 설정합니다. `/api/config`는 브라우저용 공개 설정만 전달합니다. `service_role`·secret 키는 앱에 넣지 않습니다.
3. Supabase Auth의 Google 공급자를 설정하고 PKCE 복귀 주소를 등록합니다. 이번 설정의 주소는 `https://s09-chroma.vercel.app/`, `http://127.0.0.1:3090/`, `http://localhost:3090/`입니다. 공개 앱에서 Google 로그인 화면 진입과 공개 복귀 주소를 확인했습니다. 실제 Google 계정 승인 후 앱으로 돌아오는 전체 왕복은 미실시입니다.

비로그인 상태에서는 로그인 안내가 있는 hero만 표시합니다. 업로드·URL 입력·보드·로컬 카드 앱을 초기화하거나 조회하지 않습니다. 설정 누락이나 연결 실패도 안내 화면에서 해결하며 게스트 보드로 전환하지 않습니다. 로그인 후에는 DB의 전체 공유 카드를 불러옵니다. 기존 브라우저 카드는 자동 업로드하지 않으며, **이 브라우저의 카드 가져오기**를 눌러 복사합니다. 가져온 뒤에도 브라우저 원본은 유지됩니다.

## 사용 흐름

1. Google 로그인 후 JPG·PNG·WebP 파일을 놓거나 이미지 추가를 누릅니다. 공개 이미지 주소를 URL 입력란에 붙여넣어 추가하거나 업로드 영역에 드롭할 수도 있습니다.
2. 자동 저장된 카드에서 원본·픽셀 보기를 전환하고, 색을 클릭해 HEX를 복사합니다.
3. 자세히 보기에서 세밀·픽셀 스타일·원본 색 유지를 선택하고 밀도 32·64·96·128칸이나 이름을 변경합니다. 변경 사항도 자동 저장됩니다.
4. PNG 저장으로 픽셀아트를 내려받고 새로고침해 카드가 유지되는지 확인합니다.
5. 카드 우상단 휴지통 또는 상세의 삭제 버튼을 누르고 대상 이름을 확인합니다. 계속 보관·Escape는 취소하고, 삭제 성공 후에만 카드가 사라집니다.
6. 필요하면 이 브라우저의 기존 카드를 가져옵니다. 다른 로그인 사용자도 같은 카드를 추가·편집·삭제할 수 있으며 변경 사항은 새로고침 후 확인합니다. 로그아웃하면 로그인 안내 화면으로 돌아갑니다.

모든 픽셀 모드는 추출한 5색 팔레트와 독립적으로 처리합니다.

- **세밀**: 새 업로드 기본값은 96칸입니다. PixelOE의 얇은 윤곽 처리·색 보정·5단계 Gaussian 보정 후 칸마다 우세한 색을 선택하고, Lab 공간의 최대 64색으로 정리합니다. 디더링은 없습니다. Python 비교판의 Pillow 타일 양자화는 브라우저에서 결정적인 RGB 2-means로 대체했으므로 일부 픽셀·색은 다릅니다.
- **픽셀 스타일**: 칸당 최대 16개 표본의 알파 가중 중앙값으로 튀는 질감을 줄이고, 별도로 만든 최대 32색으로 단순화합니다. 디더링은 사용하지 않습니다.
- **원본 색 유지**: 각 칸 중심의 원본 RGBA를 그대로 가져옵니다. 별도의 색상 양자화나 5색 제한은 없으며, 해상도를 줄이면 샘플에 포함되는 색의 수는 원본과 달라질 수 있습니다.

기존 카드에 모드 정보가 없으면 원본 색 유지로 복원하고 저장된 PNG도 보존합니다. 저장된 픽셀 스타일 카드도 자동으로 재생성하지 않습니다. 기존 이미지에 새 표현을 적용하려면 자세히 보기에서 모드와 밀도를 선택합니다. 변환·저장 중에는 설정을 잠그고, 실패하면 기존 설정과 이미지를 유지합니다.

픽셀 카드에서는 이미지 전체를 표시합니다. PNG는 격자를 정수 배율로 선명하게 확대하며 긴 변 최대 1,600px로 내보냅니다. 비율은 격자 계산의 반올림 오차가 있을 수 있습니다.

## 저장과 지원 범위

- IndexedDB의 기존 원본 Blob·미리보기·픽셀 PNG·팔레트·설정은 명시적 가져오기 대상으로 보존합니다. 비로그인 상태에서 브라우저 카드를 조회하거나 새 게스트 카드를 만들지 않습니다.
- 로그인 후 `s09_cards` 전체의 메타데이터와 비공개 Storage `s09-chroma-images`의 이미지를 복원합니다. 별도 초대 없이 모든 인증 계정이 같은 보드를 읽고 추가·편집·삭제하며 익명 접근은 거절합니다.
- `s09_cards.user_id`는 최초 등록자입니다. 신규 카드는 로그인한 본인 등록자로만 생성하고 직접 등록자 변경을 차단합니다. 이미지 경로 `creator/card/version/source|thumbnail|pixel`은 타사용자가 편집해도 최초 등록자 prefix를 유지합니다.
- 여러 사용자·탭의 저장은 revision CAS로 오래된 작업을 거절하고 다시 불러오도록 안내합니다. 삭제는 advisory lock과 row lock을 사용하는 트랜잭션으로 직렬 처리하며 삭제 자체에 expected revision 비교는 없습니다. 다른 사용자의 변경은 새로고침 후 표시하며 실시간 자동 갱신은 제공하지 않습니다.
- 클라우드 카드 삭제와 교체된 이미지의 정리 작업을 DB 트랜잭션에 함께 기록합니다. 파일 삭제 실패는 편집·삭제 실행자에게 귀속된 `s09_image_cleanup`에 남겨 그 계정의 목록 조회·저장·삭제 시 재시도합니다. 다른 계정이 대신 자동 재시도하지 않습니다. 이미 완료된 카드 삭제를 파일 정리 실패 때문에 되돌리지는 않습니다.
- 저장 트랜잭션이 완료된 후에만 카드를 표시합니다. 저장·복원 실패는 오류로 안내하고 복원 재시도 버튼을 제공합니다.
- 클립보드 권한이 제한되면 선택 가능한 HEX 입력이 나타납니다. 일반 복사 키로 복사할 수 있습니다.
- 파일당 최대 12MiB, 최대 4천만 픽셀·한 변 16,384px를 지원합니다. 완전히 투명한 이미지, 손상된 이미지와 지원하지 않는 형식은 저장하지 않습니다.
- 세밀 모드의 내부 작업 이미지는 최대 4백만 픽셀입니다. 극단적으로 긴 이미지가 이 한도를 넘으면 밀도를 줄이도록 안내합니다. 변환이 60초 안에 끝나지 않으면 실패로 안내하며 저장된 이미지는 보존합니다.
- 데스크톱 Chrome 계열에서 확인했습니다. 모바일 전용 화면은 이번 범위에 포함하지 않습니다.
- 주소 다운로드는 CORS를 따릅니다. JPG·PNG·WebP 직접 주소만 지원하고 12MiB·15초로 제한합니다. CORS 차단·네트워크 실패 시 원본 파일 업로드로 안내하며 실패한 주소는 입력란에 남깁니다.
- 메인 그래픽은 스캔→픽셀 조립→5색으로 12초마다 반복합니다. 모션 감소 설정에서는 완성 이미지로 정지합니다.
