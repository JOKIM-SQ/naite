# Chroma — 색으로 모으는 영감

S09 컬러 트렌드 무드보드. 이미지를 한 번 드롭하면 대표색 다섯 개와 픽셀아트를 함께 생성하고, IndexedDB에 자동 저장합니다. 원본 색 유지와 잔질감을 정리하는 32색 픽셀 스타일을 선택할 수 있습니다.

## 실행

Node.js 22 이상에서 `09` 디렉터리를 기준으로 실행합니다.

```sh
npm ci
npm run dev
```

로컬 주소: [http://127.0.0.1:3090/](http://127.0.0.1:3090/)

```sh
npx tsc --noEmit
npm run lint
npm test
npm run build
```

빌드와 개발 시작 시 공식 Color Thief 브라우저 모듈을 `public/vendor`에 준비합니다. 생성한 vendor 파일과 node_modules는 Git에 포함하지 않습니다. API 키나 별도 서버 설정은 필요하지 않습니다.

## 사용 흐름

1. JPG·PNG·WebP 파일을 업로드 영역에 놓거나 이미지 추가를 누릅니다. 여러 장을 함께 처리할 수 있습니다.
2. 자동 저장된 카드에서 원본·픽셀 보기를 전환하고, 색을 클릭해 HEX를 복사합니다.
3. 자세히 보기에서 원본 색 유지·픽셀 스타일을 선택하고 밀도 32·64·128칸이나 이름을 변경합니다. 변경 사항도 자동 저장됩니다.
4. PNG 저장으로 픽셀아트를 내려받고 새로고침해 카드가 유지되는지 확인합니다.
5. 삭제 확인 창에서 삭제하거나 계속 보관을 선택합니다.

두 모드 모두 추출한 5색 팔레트를 사용하지 않습니다.

- **픽셀 스타일**: 새 업로드 기본값은 64칸입니다. 칸당 최대 16개 표본의 알파 가중 중앙값으로 튀는 질감을 줄이고, 별도로 만든 최대 32색으로 단순화합니다. 디더링은 사용하지 않습니다.
- **원본 색 유지**: 각 칸 중심의 원본 RGBA를 그대로 가져옵니다. 별도의 색상 양자화나 5색 제한은 없으며, 해상도를 줄이면 샘플에 포함되는 색의 수는 원본과 달라질 수 있습니다.

기존 카드에 모드 정보가 없으면 원본 색 유지로 복원하고 저장된 PNG도 보존합니다. 기존 이미지에 새 스타일을 적용하려면 자세히 보기에서 픽셀 스타일을 선택합니다. 변환·저장 중에는 설정을 잠그고, 실패하면 기존 설정과 이미지를 유지합니다.

픽셀 카드에서는 이미지 전체를 표시합니다. PNG는 격자를 정수 배율로 선명하게 확대하며 긴 변 최대 1,600px로 내보냅니다. 비율은 격자 계산의 반올림 오차가 있을 수 있습니다.

## 저장과 지원 범위

- 이 브라우저·이 주소의 IndexedDB에 원본 Blob, 미리보기, 픽셀 PNG, 팔레트, 이름·설정을 저장합니다. 다른 브라우저·기기·배포 주소로 동기화하지 않습니다.
- 저장 트랜잭션이 완료된 후에만 카드를 표시합니다. 저장·복원 실패는 오류로 안내하고 복원 재시도 버튼을 제공합니다.
- 클립보드 권한이 제한되면 선택 가능한 HEX 입력이 나타납니다. 일반 복사 키로 복사할 수 있습니다.
- 파일당 최대 12MiB, 최대 4천만 픽셀·한 변 16,384px를 지원합니다. 완전히 투명한 이미지, 손상된 이미지와 지원하지 않는 형식은 저장하지 않습니다.
- 데스크톱 Chrome 계열에서 확인했습니다. 모바일 전용 화면은 이번 범위에 포함하지 않습니다.
