## 처리 상태 패널 — 최신 변경

팔레트·픽셀 테마의 처리 패널은 파일 수신 직후 원본 미리보기와 파일명·배치 순서(n/N)·경과 초를 표시한다. 실제 이미지 읽기→대표색 추출→픽셀 변환→저장 단계에 맞춰 안내하며, 추출 뒤에는 실제 대표색 5개를 표시한다. URL은 다운로드 단계를 먼저 표시한다. 12초 이상 대기하면 첫 변환 준비·큰 이미지 안내를 제공하며 임의의 완료율이나 남은 시간을 표시하지 않는다. 저장 성공 후에만 완료와 카드를 표시하고, 오류 시 재시도 안내를 남긴다. 상세 재변환도 변환·저장 오버레이를 표시한다. 모션 감소 설정에서는 장식을 정지하고 단계·경과 시간 텍스트를 유지한다.

자동 테스트 144/144개·타입·린트·빌드 통과, 독립 리뷰 CLEAR/APPROVE·관련 검사 60/60을 확인했습니다. 프레임 콜백 중단 시에도 처리 큐가 진행하며 실패 후 재시도·저장 전 카드 숨김·타이머와 미리보기 해제를 자동 검사합니다. 로컬 브라우저에서는 실제 처리기·Color Thief·Worker와 격리된 IndexedDB로 합성 이미지(960×720, 97,894 bytes)의 원본 미리보기·추출색 5개, 저장 전 카드 0개→실제 커밋 후 1개, 모션 감소 시 애니메이션 0개·단계 유지, 손상 파일·URL 실패 복구, 상세 저장 오버레이 해제, 혼합 배치 1개 저장·1개 실패를 확인했습니다. 테스트 경계로 작업을 대기시킨 UI 검증이며 Google 인증·클라우드 저장 왕복을 새로 확인한 결과는 아닙니다. 처리 패널 1차 공개 배포 `dpl_FpFupxAk9eHtmRnVpStqGUhfsS4g`에서 앱 관련 4파일·문서 2파일의 HTTP 200, 코드 SHA-256의 `3af08f3` 일치와 당시 문서 초안 일치, 비로그인 작업 영역 hidden/inert·카드 0개·처리 패널 숨김·가로 넘침 없음을 확인했습니다. 이후 URL 수신 제목 수정도 전체 144개 검사와 독립 리뷰를 통과했습니다. 최종 후속 배포 식별자·코드 해시는 `SUBMISSION.md`와 `SPIKE.md`에 별도 기록합니다. 앞 절의 배포 식별자와 134개 검사는 처리 패널 추가 전 공유 보드 이력입니다. 실제 경과 초에는 검증용 수동 대기가 포함될 수 있어 성능 측정값으로 인용하지 않습니다.

1. 공개 앱의 로그인 안내에서 Google 로그인 후 공유 보드를 엽니다.
