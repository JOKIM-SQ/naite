01누가 쓰나

대상 가설: 출장·구매 영수증을 모아 정리하는 팀원. 영수증 3장의 날짜와 결제금액을 옮겨 적는 상황을 대상으로 한다. 실제 사용 빈도는 기록 없음.

02지금은

사진을 하나씩 열어 날짜·총액·품목을 표에 옮겨 적는다. 기존 작업 소요 시간은 기록 없음.

03없앨 동작 하나

영수증에서 날짜·최종 결제금액·품목을 찾아 처음부터 다시 타이핑하는 동작.

04핵심 기능 1개

영수증 사진 최대 3장을 올리면 원본을 보관하고 날짜·최종 결제금액·품목을 추출해 표로 보여주며, 틀린 값은 직접 수정하면 자동 저장한다.

05안 만드는 것 3개

  • 별도 이메일·비밀번호 회원가입
  • 관리자 페이지
  • CSV 다운로드·회계 프로그램 연동

06성공 판정

  • 사진 3장의 날짜·최종금액·품목이 실제 추출되어 표에 표시되고, 원본을 다시 열 수 있다. 수정 후 새로고침해도 값이 유지된다. 업로드 뒤 필수 클릭 0회, 필드 수정 완료 횟수 총 3회 이하를 검증한다. 최초 추출의 날짜·총액이 모두 맞은 사진 수 N/3을 실제 정답과 비교해 보고한다. 공개 URL·모바일·문서 2개·3분 시연을 확인한다. 현재 웹 가이드 기준 제출은 9월 17일 목 18:00, 데모는 9월 18일 금 09:30이다.

07내 옵션 + 이유

Supabase Storage에 원본 파일을, Postgres에 원본 경로와 추출·수정 결과를 저장한다. 기존 프로젝트의 Supabase 및 Claude 호출 경험을 재사용한다. OCR 공급자는 Claude Haiku 4.5로 명시하며 글자 인식과 필드 추출을 한 번에 처리한다.

08리스크 + 검증법

걱정되는 것: 흐린 글씨, 모호한 날짜, 소계와 최종금액 혼동, 외부 키·Storage 연결. 읽을 수 없는 값은 null로 남기고 원본 옆에서 수정한다.
화요일 스파이크로 확인: 원본 1장 저장 → Haiku 구조화 추출 → 실제 정답 대조. 첫 저장 시간·막힌 지점·인식 결과 기록.
