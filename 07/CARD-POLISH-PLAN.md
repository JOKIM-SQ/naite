# 영수증 카드 표시 개선

1. 완료 — 넓은 사진 헤더를 작은 우측 원본 미리보기로 바꾸고 상호·금액·카테고리 위계와 조작 영역 개선.
2. 완료 — /browse로 데스크톱·모바일, 긴 상호명·실패 상태·편집·삭제 확인창 검증 및 독립 코드 검토.
3. 진행 중 — 필수 검사, 커밋, 기존 승인 범위의 프로덕션 배포와 공개 반영 확인.

범위: 카드 표현과 분류 스타일 연결. 분석·저장·집계 계약은 유지한다. 시각 변경에는 CSS 값을 반복하는 단위 테스트를 추가하지 않고 기존 회귀 검사와 실제 화면 관찰을 사용한다.

4. 완료 — initial-b 등록 방식 확인, 공개 기획서·리포트 메타데이터 통일, 제출 문구·TSV·데모 순서 준비. 실제 등록과 미측정 정확도 값은 구분.
