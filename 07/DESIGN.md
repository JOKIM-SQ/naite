# S07 UI/UX 개선 작업

## 의도와 범위

최근 S04·S05·S06의 타이포그래피, 분명한 제품 개성, 입력에서 결과로 이어지는 구성을 참고해 영수증 정리기의 시각적 완성도와 사용 흐름을 높인다. 사용자 요청에 따라 S07의 화면을 개선하며 서버·DB·OCR 계약과 제외 기능은 유지한다.

## 작업 상태

1. [완료] 최근 3주차 공개 화면 및 소스 비교, S07 기존 첫 화면 기록
2. [완료] 종이·녹색 기반 화면과 업로드/연결/편집 상태 개선
3. [완료] 데스크톱·태블릿·모바일 실제 조작, 자동 검사 42개 및 독립 동작/시각 검증
4. [차단: 배포 승인 필요] 구현·근거 커밋 완료(6460e93). 자동 승인 검토가 소스 외부 전송 및 운영 사이트 갱신의 명시적 승인 부족으로 Vercel 배포를 거절했다. 로컬 미리보기에서 확인 가능하며, 승인 후 기존 S07 사이트 갱신 및 공개 화면 검증을 진행한다.

## 디자인 기준

- S04의 대형 제목과 입력 중심 첫 화면, S05의 종이색·짙은 녹색·세리프 대비, S06의 명시적인 상태 피드백을 참고한다.
- 브랜드는 Paper trail, 한국어 제품명은 영수증 정리기. 한국어 제목과 하나의 사진 선택 버튼으로 용도를 즉시 전달한다.
- 따뜻한 종이색, 짙은 녹색, 구분선과 여백으로 구성한다. 실제 영수증 종이를 연상시키는 업로드 면이 주요 시각 요소다.
- Pretendard Variable은 한국어 UI, Instrument Serif는 영문 브랜드에 사용한다. CSS 변수로 색·폰트·크기 체계를 유지한다.
- 데스크톱은 소개/업로드를 나란히 배치하고, 아래에 요약표와 원본/편집 화면을 둔다. 모바일은 세로 흐름, 읽기 쉬운 입력 글자, 충분한 터치 영역을 우선한다.
- 연결 문제는 업로드 바로 옆, 처리 상태는 기록 영역, 저장 피드백은 편집 영역에 표시한다. 추정 진행률·가짜 정확도는 표시하지 않는다.
- 데이터가 없는 화면도 완성된 상태로 디자인한다. 장식용 영수증 금액이나 실제 결과로 오인할 샘플을 배포하지 않는다.
- 로그인·관리자·CSV/회계 연동 등 새 제품 기능은 추가하지 않는다. 공통 제출 문서 템플릿은 유지한다.

## 최초 관찰

- 넓은 화면에서 소개 우측이 비어 있고 업로드/기록이 아래로 밀린다.
- 9~11px 안내와 36px 품목 입력/삭제 버튼이 모바일 사용에 작다.
- 연결 실패 안내가 업로드와 떨어져 있어 비활성 버튼의 이유를 찾기 어렵다.
- 결과 목록의 파일명 위주 표시는 영수증을 구분하기 어렵게 한다.
- 편집·오류·최초 추출값 기능은 이미 있어 동작을 보존하면서 정보 위계와 피드백을 개선한다.

## 검증 경계

로컬 QA 서버는 실제 UI/API 코드와 테스트용 외부 응답을 사용한다. 화면/동선 검증이며 실제 Supabase 저장 또는 Haiku OCR 정확도의 근거는 아니다. 실제 서비스 연결은 기존 키·SQL 설정 대기가 계속 적용된다.

## 앱 아이콘·분석 미리보기 추가 — 2026-09-17

사용자가 앱 아이콘과 메인 분석 그래픽/애니메이션을 명시적으로 요청했다. 기존 범위 제한의 애니메이션 항목은 이번 요청에 한해 적용하지 않는다.

1. [완료] 기존 영수증 마크의 앱/홈 화면 아이콘, 주요 작업 아이콘, 영수증 → 날짜·금액·품목 그래픽 구현
2. [완료] 화면 진입 시 한 번 재생·다시 보기·움직임 줄이기 동작과 반응형/업로드 회귀 검증. 고대비 모드의 삭제 아이콘 누락을 재현하고 수정했다.
3. [완료] 전체 검사 49개 테스트·빌드 및 독립 리뷰 통과, 근거 기록과 로컬 미리보기 갱신. 이 작업 단위로 커밋한다. 공개 배포는 앞선 승인 요청이 미응답이므로 실행하지 않았다.

그래픽은 '정리 과정 미리보기'로 표시하며 실제 OCR 진행률이나 인식 결과로 표현하지 않는다. 모션은 5초 이내 한 번 재생하고 정지하며, 다시 보기로 재생한다. 기본 정지 그림에서도 기능을 이해할 수 있어야 한다. 외부 애니메이션 라이브러리, 가짜 정확도, 새 서버 기능은 추가하지 않는다.
