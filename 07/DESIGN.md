# Paper trail — 지출 대시보드 디자인

## 현재 범위

영수증 사진을 올리고 정리하는 화면을 개인 지출 대시보드로 확장한다. 사용자가 요청한 네 가지 분류(쇼핑·장보기·외식·그 외), 분류별 탐색, 지출 요약, 월별·분류별 차트, 영수증 수정·삭제를 한 작업 공간에서 제공한다. 품목 목록과 통화·모델 입력 UI는 두지 않는다. 여러 통화가 실제로 존재할 때만 조회용 통화 필터를 표시한다.

기존 로그인, 업로드, 연결 상태와 자동 분석 일러스트의 5.2초 반복 동작을 보존한다. 원본 이미지와 모든 값은 사용자의 실제 데이터만 표시한다. 로그인 전·등록 전·조회 결과 없음 상태는 독립적인 빈 화면이다.

## 시각 체계

- 브랜드: **Paper trail.** 기존 영수증 마크와 브랜드 점을 유지한다.
- 색: `--paper #f5f3ed`, `--surface #fffefa`, `--green #254f3f`, `--sidebar #eeeee6`. 오커색은 보조 강조, 오류색은 실제 오류에만 쓴다.
- 글꼴: Instrument Serif 영문 제목·브랜드와 Pretendard Variable 한국어 UI를 조합한다. 숫자는 tabular-nums로 정렬한다.
- 경계: 1px 선, 4–5px 모서리, 거의 보이지 않는 종이 그림자. 과한 입체 효과 없이 면과 간격으로 정보를 구분한다.
- 아이콘: 22px viewBox의 선형 SVG를 사용하고 모든 아이콘에 같은 선 굵기·끝 모양을 적용한다. 의미는 텍스트 또는 접근성 이름으로도 전달한다.
- 참고: S05의 사이드바·모듈식 카드·크림/녹색, S04의 세리프 대비, S06의 분명한 상태 표시를 현재 Paper trail 언어로 옮긴다.

## 정보 구조

1. **사이드바:** 대시보드, 전체 영수증, 네 가지 분류 및 실제 건수. 하단에 로그인 계정과 로그아웃을 배치한다.
2. **페이지 머리:** 영문 대시보드 제목, 한 줄 설명, 조회 기간. 통화 필터는 혼합 통화가 있을 때에만 보인다.
3. **업로드 배너:** 기존 영수증 → 날짜·금액·분류 일러스트와 짧은 안내, 사진 선택 또는 Google 로그인 버튼. 오류는 바로 아래에 둔다.
4. **지출 요약:** 총 지출, 처리한 영수증, 이번 달/선택한 달 지출, 건당 평균. 총 지출에 짙은 녹색 면을 적용한다. 집계 전에는 대시를 사용한다.
5. **차트:** 월별 지출 막대와 네 가지 분류 도넛·범례. 데이터가 없으면 중립적인 빈 도형과 안내만 표시한다.
6. **영수증:** 원본 썸네일, 상호명, 날짜, 분류, 금액, 상태, 수정·삭제 버튼. 상시 입력 폼을 제거하고 수정 버튼에서 원본과 편집 필드를 함께 여는 모달로 연결한다.

분류 화면에서는 대시보드 지표를 숨기고 같은 필터·검색·카드 레이아웃을 재사용한다. 원본 파일명보다 상호명과 금액을 먼저 읽을 수 있도록 배치한다.

## 상태와 접근성

- 로그인 전에는 로그인 버튼을 업로드 배너에 표시하고 실제 빈 대시보드를 유지한다. 샘플 영수증·가짜 금액·추정 진행률은 배포 화면에 넣지 않는다.
- 업로드 연결 중, 분석 중, 읽기 실패, 저장 실패, 삭제 마무리 필요 상태를 텍스트로 구분한다. 오류 메시지를 색으로만 전달하지 않는다.
- 삭제는 네이티브 확인 모달에서 실행한다. 재시도 가능한 삭제 오류도 같은 화면에서 설명한다.
- 수정 모달은 네이티브 `dialog`를 사용하며 제목, 닫기 버튼, 원본 사진, 날짜·금액·상호명·분류 입력, 자동 저장 상태로 구성한다.
- 주요 탐색에는 현재 페이지 상태를, 입력에는 연결된 라벨을, 상태 갱신에는 `role=status` 또는 `role=alert`를 제공한다.
- 키보드 포커스, 본문 건너뛰기, 40px 이상 모바일 조작 영역, native dialog 포커스 관리, reduced-motion을 지원한다.
- 일러스트는 기존 5.2초 반복을 유지한다. 화면 밖·숨긴 탭·움직임 줄이기 환경에서는 정지한다. 품목 표시만 분류로 바꾸며 모션 제어 모듈은 수정하지 않는다.

## 반응형 규칙

- 넓은 화면: 232px 고정 사이드바, 최대 1436px 본문, 4열 지표, 2열 차트, 3열 영수증 카드.
- 중간 화면: 지표·영수증 2열, 차트 1열. 원본 카드의 내용이나 차트 종류를 생략하지 않는다.
- 760px 이하: 상단 브랜드·메뉴 버튼, 화면을 덮는 사이드바와 배경 닫기 버튼. 본문은 전체 폭을 쓴다.
- 540px 이하: 2열 지표와 1열 차트, 원본 썸네일 96px과 내용을 나란히 둔 영수증 카드, 한 줄 전체 폭 검색, 세로형 수정 모달. 날짜·금액 입력은 2열을 유지한다.

## 앱과의 계약

- 탐색: `sidebar`, `mobile-nav-toggle`, `sidebar-backdrop`, `[data-view]`, `[data-count]`.
- 대시보드: `dashboard-panel`, `kpi-total`, `kpi-count`, `kpi-month`, `kpi-month-label`, `kpi-average`, `kpi-context`, `monthly-chart`, `category-chart`, `category-legend`, `chart-empty`.
- 기록: `records-panel`, `receipts-title`, `receipt-count`, `receipt-search`, `receipt-list`, `empty-state`, `empty-title`, `empty-copy`, `workspace-status`, `review-note`, `view-all-receipts`.
- 필터: `month-filter`, `currency-filter`, `currency-filter-wrap`.
- 수정: `receipt-dialog`, `receipt-dialog-title`, `receipt-dialog-close`, `receipt-dialog-content`.
- 삭제: `delete-dialog`, `delete-dialog-title`, `delete-message`, `delete-error`, `delete-cancel`, `delete-confirm`.
- 기존 인증·업로드 및 분석 모션 요소의 ID를 유지한다. 동적으로 생성하는 카드·차트·폼 클래스는 app.js 작업과 직접 조율한다.

## 검증 범위

HTML/CSS 정적 구조·ID 계약 확인을 수행한다. 기능 테스트와 전체 빌드, 실제 데스크톱·390px 모바일 화면 및 키보드 동작 검증은 통합 단계에서 수행한다. 로컬 QA의 외부 응답은 테스트용이며 실제 Google 로그인·OCR 정확도·Supabase 저장 성공의 근거가 아니다. 개인 영수증 스크린샷은 저장소에 추가하지 않는다.

## 이전 공개 화면

2026-09-17까지의 화면은 입력 중심 영수증 정리기였으며, 공개된 분석 반복 동작은 커밋 `6042003`에 포함되어 있다. 이번 대시보드 개편에서는 기존 반복 동작과 브랜드를 이어받고 정보 구조를 변경한다. 과거의 품목 편집·최근 30장 안내·일회 재생 기준은 현재 화면에 적용하지 않는다.
