# 분석 미리보기 반복 재생 TDD

2026-09-17. 사용자 요청에 따라 기존 1회 재생·다시 보기 계약을 자동 반복으로 변경했다. 미리보기는 실제 API 처리 진행이나 OCR 결과와 무관하다.

## Red

기존 구현을 유지한 채 새 경계 테스트로 교체했다. `node --test public/analysis-motion.test.mjs`에서 **7개 실패, 기존 cleanup 경계 1개 통과**를 확인했다.

- 보이는 동안 종료 타이머가 없어야 하지만 기존 구현은 타이머를 만들었다.
- 화면 밖으로 나가도 기존 구현은 노출 관찰을 이미 종료해 정지하지 않았다.
- 탭 복귀, 최초 비활성 탭의 활성화, 움직임 줄이기 해제 시 자동으로 재개하지 않았다.

## Green

- 다시 보기 버튼과 관련 스타일·이벤트를 제거했다.
- JS는 화면 노출·탭 활성 여부·움직임 줄이기 설정만 관찰한다. 반복 타이머는 사용하지 않는다.
- 미리보기 절반 이상 노출 + 활성 탭 + 움직임 줄이기 해제 조건이 함께 충족되면 CSS 반복을 켠다. 조건이 달라지면 완성된 정지 그림으로 돌아가고 복귀 시 자동 재개한다.
- CSS는 모든 요소에 5.2초 주기를 공통 적용한다. 스캔 → 날짜 → 금액 → 품목 → 체크 표시 → 완성 그림 유지 → 페이드 초기화 순서다.
- 기본 그림과 움직임 줄이기 상태는 모든 추출 필드·체크 표시가 보이는 완성 형태다.

검증: `node --test public/*.test.mjs` **30개 통과, 0개 실패**. `node --check public/analysis-motion.mjs`, `git diff --check` 통과. 실제 브라우저 QA·공개 배포는 메인 작업 담당이며 이 기록은 배포 완료나 실제 OCR 연결을 주장하지 않는다.
