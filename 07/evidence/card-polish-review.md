# 영수증 카드와 분류 pill 개선 검증

## 결과
넓은 사진 헤더를 작은 우측 원본 미리보기로 바꾸고, 좌측 분류·날짜·상호·금액과 점선 아래 조작 영역으로 정리했다. 상호는 두 줄까지, 금액은 긴 값도 가리지 않고 줄바꿈한다. 일반 완료 상태 문구는 생략하되 분석·저장 중과 오류는 유지한다. 분류 색상은 쇼핑 라벤더, 장보기 세이지, 외식 살구, 그 외 회색이며 편집하면 같은 카드에서 갱신된다.

## 관찰 및 검사
- 실제 app.js와 API를 사용하는 로컬 QA 서버를 /browse로 조작했다. 외부 Auth·Storage·OCR은 모의 응답이며 화면의 데이터는 가상 테스트 기록이다.
- 320px: scrollWidth 320, viewport 320. 카드 조작 버튼 높이 44px. 긴 상호·큰 금액·실패 카드도 문서 넘침 없이 표시.
- 390px: 카드 높이 약 225px. 편집 창 열기, 카테고리 장보기→외식 변경 후 닫기·자동 저장, pill 텍스트/data-category/살구색 바탕 동시 변경 확인.
- 저장 실패: 편집 입력·모달 유지. 카드의 저장 중, 저장 확인 필요가 display:flex로 남는다. 모의 장애 해제 후 저장·닫기 복구.
- 삭제: 로컬에서 이번에 추가한 경계 테스트 카드 두 개를 삭제 확인창으로 제거했다. 기존 카드 유지.
- 1440px: 3열 카드, 금액과 수정·삭제 정렬 확인. 1920px에서 이전의 160px 썸네일 규칙이 남지 않고 112px 유지.
- 분류 pill 텍스트/바탕 대비: 쇼핑 4.65, 장보기 5.28, 외식 4.71, 그 외 4.66. 해당 네 색상 조합만의 계산이며 전체 접근성 인증이 아니다.
- npx tsc --noEmit, npm run lint, npm test, npm run build, git diff --check 성공. 테스트 134개 통과. TypeScript checkJs:false의 한계는 기존과 같다.
