# S07 분석 미리보기 반복 재생 코드 리뷰

검토일: 2026-09-17. 읽기 전용 독립 리뷰이며 이 보고서 외 파일은 변경하지 않았다.

## 판정

사용자가 승인한 새 계약인 자동 반복 재생·다시 보기 제거를 기준으로 **확정 P1/P2 코드 결함 없음**. 이전 일회 재생 계약은 이번 검토 기준으로 적용하지 않았다. 이 리뷰는 공개 배포 수행 또는 완료를 의미하지 않는다.

## 검토한 변경

- `public/analysis-motion.mjs`
- `public/analysis-motion.test.mjs`
- `public/index.html`
- `public/styles.css`

## 확인 결과

1. 관찰 API가 있는 환경에서 미리보기 노출 비율 0.5 이상, 활성 탭, 동작 줄이기 해제 조건이 함께 충족돼야 `data-playing="true"`가 된다. 최초 재생 후에도 관찰을 유지하므로 화면 이탈과 재진입을 반영한다.
2. 화면 이탈·탭 숨김·동작 줄이기 활성화는 반복 애니메이션 선택자를 해제한다. 기본 스타일은 스캔선을 숨기고 날짜·금액·품목·체크 표시를 모두 보여 주는 완성된 정지 그림이다. 조건이 회복되면 자동으로 새 주기를 시작한다.
3. 최초 비활성 탭과 최초 동작 줄이기 설정도 정지 상태로 시작한다. 동작 줄이기 해제 시 현재 노출·탭 상태를 함께 확인하므로 화면 밖에서 잘못 재개하지 않는다. CSS의 `prefers-reduced-motion` 차단도 유지된다.
4. 모든 모션 요소는 공통 5.2초 주기와 `infinite` 반복을 사용한다. 날짜·금액·품목·체크 표시는 같은 주기 안의 키프레임으로 순서를 지정한다. 이전 종료 타이머·일회 재생용 지연·버튼 의존성은 제거됐다.
5. 다시 보기 버튼은 HTML에서 제거됐으며 모듈과 CSS에도 관련 참조가 남아 있지 않다. 제거된 노드를 조회하거나 이벤트를 등록하는 경로가 없다.
6. 정리 함수는 관찰 및 설정·가시성 리스너를 해제하고 정지 그림으로 돌린다. 관찰 API가 없는 환경에서는 활성 탭·동작 줄이기 설정을 기준으로 동작하는 기존 폴백 경계를 유지한다.
7. 미리보기는 실제 OCR/API/영수증 자동 저장과 독립적이다. 업로드 버튼과 입력·저장 코드 변경은 없으며, 기존 고대비 mask 아이콘 보정도 유지된다.

## 직접 실행한 검증

`node --test public/analysis-motion.test.mjs public/app.test.mjs public/receipt-view.test.mjs`

결과: **30개 통과, 0개 실패**. 모션 상태 경계 8개, 기존 UI 회귀 7개, 값 검증·자동 저장 15개다.

검증 범위에는 화면 노출 경계, 화면 이탈·재진입, 탭 전환, 초기 비활성 탭, 초기 및 실행 중 동작 줄이기 변경, 관찰 API 폴백, 정리 후 재실행 방지, 날짜·입력값·포커스 보존, 저장 실패·충돌 처리가 포함된다.

## 실제 화면 검증의 구분

메인 `/browse` QA는 7.1초 관찰 중 반복 iteration 0→1 진행과 다시 보기 버튼 부재를 확인했다고 전달했다. 해당 브라우저 검증은 메인 수행 결과이며, 이 독립 리뷰에서는 브라우저를 실행하거나 공유 브라우저를 조작하지 않았다. 모바일·동작 줄이기 실제 화면 검증과 공개 배포는 메인 작업에서 별도로 완료한다.
