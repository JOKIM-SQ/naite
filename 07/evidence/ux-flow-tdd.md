# S07 업로드·결과 안내 TDD 기록

2026-09-16. `public/app.js`의 실제 UI 제어 코드와 기존 자동저장·검증 함수를 `node:test`에서 실행했다. DOM, 파일 읽기, 네트워크 응답은 테스트 경계용 대역이며 실제 OCR 결과나 브라우저 시각 검증을 뜻하지 않는다.

## 실패 확인

- 최초 추가한 5개 테스트가 기존 코드에서 실패하고 기존 15개 테스트는 통과했다.
- 연결 상태 속성이 없고, 작업 공간 안내가 비어 있으며, 요약에는 파일명만 있고, 새 카드로 이동하지 않는 것을 확인했다.
- 날짜 선택기 테스트는 `type=text`로 실패했다.
- 미완성 날짜 테스트는 브라우저의 `validity.badInput=true`, `value=''`를 재현했다. 기존 값 보존을 기대했지만 PATCH가 1회 발생해 실패했다.

## 구현·통과

- `loading / ready / error`가 업로드 버튼·상태 라벨·파일 드롭 허용 여부를 함께 바꾼다. 503은 서버 설정 설명 대신 다시 연결 안내를 표시한다.
- 진행·완료·실패 수를 실제 영수증 상태로 집계한다. 실패한 사진 재시도는 즉시 진행 수에 반영한다.
- 영수증 번호·상호·파일명을 요약에 표시한다. 저장 응답이 입력 포커스나 미완성 값을 덮어쓰지 않는다.
- 허용된 첫 새 카드로 한 번 이동한다. 움직임 줄이기 설정은 즉시 이동을 사용한다. 포커스는 옮기지 않는다.
- 원본 상세에 `수정한 필드 N개`와 품목 전체를 1개 필드로 합산한다는 설명을 둔다.
- 날짜 선택기는 ISO 값을 그대로 저장하며, 미완성 날짜의 `badInput`은 기존 입력 오류 처리로 보존한다.

최종 실행: `node --test public/*.test.mjs` → **22개 통과, 0개 실패**. `node --check public/app.js`, `git diff --check` 통과. 실제 브라우저 통합 QA는 메인 작업에서 별도로 확인한다.
