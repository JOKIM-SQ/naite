# 품목 추출 프롬프트 개선 — 2026-09-17

## 변경 범위

`lib/receipt-extract.mjs`의 system 프롬프트만 수정했다. 모델(Haiku 4.5), 원본 이미지, JSON 스키마, 저장 구조, 화면은 유지한다.

- 구매 상품을 인쇄 순서대로 읽고 첫·마지막 상품 누락을 재확인한다.
- 할인, 쿠폰, 세금, 보증금, 결제, 포인트, 광고 문구를 구매 품목과 구분한다.
- 원문 약어를 임의로 확장하거나 다른 익숙한 상품명으로 바꾸지 않는다.
- 명시된 수량만 사용하고, 행 금액을 단가나 인접 할인 금액과 혼동하지 않는다.
- 총액에 맞추기 위해 품목이나 금액을 만들어 내지 않는다.

## 검증과 한계

- `npx tsc --noEmit`, `npm run lint`, 기존 전체 테스트 86개, `npm run build`, `git diff --check` 통과.
- 독립 읽기 전용 검토에서 기존 상호·날짜·총액 규칙과 새 품목 지침의 충돌을 발견하지 못했다.
- 문자열 일치 테스트나 모의 OCR 응답을 실제 인식률 개선의 증거로 사용하지 않는다.
- 실제 API 전후 비교는 아직 미실행이다. Vercel의 Claude 키가 Sensitive로 설정돼 있고 로컬에는 키가 없어, 사용자의 로컬 환경 설정을 기다리고 있다.
- 원본 사진에서 기대 품목·행 금액·안내문 제외 기준을 정한 비교 스크립트와 변경 전 추출기를 비공개 임시 경로에 준비했다. 사용자 사진·원문 결과·비밀키는 저장소에 추가하지 않았다.
- 저장된 최초 추출값과 수동 수정값은 재시도에서도 보존된다. 배포 후 새 프롬프트 결과를 확인하려면 같은 사진을 새로 업로드한다.
