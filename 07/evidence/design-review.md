# S07 디자인 개선 검증

## 기준

사용자 요청: 최근 2~3개 주차 프로젝트처럼 UI/UX를 유려하게 구현한다. `/design-review`의 화면 관찰 → 수정 → 동일 화면 재검증 절차를 적용한다. `/browse`로 S04·S05·S06·S07을 직접 비교했다. S05는 공개 로그인 화면까지만 관찰했다.

## 검증 시나리오

- 초기 연결, 연결 실패 및 다시 연결: 버튼/상태가 같은 위치에서 설명되고 잘못 활성화되지 않는다.
- 비어 있는 기록: 업로드 전 용도를 이해할 수 있고 가짜 데이터가 없다.
- 실제 파일 3개 선택: 테스트 서버에서 즉시 원본 표시, 상태 전환, 결과 이동 및 요약 확인.
- 날짜 선택·금액 수정·품목 추가/삭제: 자동 저장 후 새로고침에도 유지, 최초 추출값 보존.
- 분석 실패: 해당 영수증에서 재시도, 다른 결과 유지.
- 파일 4장/잘못된 금액: 오류 문구와 저장 상태 확인.
- 1440/1024/768/390/375/320px: 문서 가로 넘침, 입력 크기, 원본·편집 배치 확인.
- 키보드 포커스, 줄임 동작 설정, 콘솔 예외 및 폰트 적용 확인.

## 검증 한계

현재 QA 결과는 외부 서비스 응답을 대체하는 로컬 서버에서의 UI/실제 프런트 코드 검증이다. 실제 OCR·Supabase 저장·N/3 정확도는 API 키와 SQL 설정 이후에 검증해야 한다. 점수나 목업 비교 결과를 실측인 것처럼 기록하지 않는다.

## 동작 검증

- 자동 검사: `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build` 종료 0. 테스트 42/42 통과. TypeScript는 기존 설정의 JS emit 없는 컴파일 확인이며 strict 타입 검증을 의미하지 않는다.
- 기존 35개에 실제 app.js를 실행하는 7개 회귀 검증을 추가했다. 연결/재연결, 상태별 장수, 빈 목록, 날짜 선택기, 미완성 날짜, 요약·입력 보존, 업로드 이동을 다룬다. `ux-flow-tdd.md` 참조.
- 독립 검증에서 날짜 일부를 지우다 만 상태의 `badInput`이 null 저장으로 이어지는 P2를 확인했다. 구현자가 같은 경계를 테스트 우선으로 수정한 뒤 검증자가 재확인했고 프런트 22/22 통과, 해당 문제 해소 및 검토 범위 내 남은 P1/P2 없음으로 판정했다.
- 검증자는 메모리 내 app.js 실행으로 폴링 실패 → 다시 연결 → 완료 복구와 다른 영수증의 입력 포커스·미완성 값 보존도 확인했다.

시각 근거는 `design/after-desktop.png`, `after-mobile.png`, `after-editor.png`, `after-mobile-editor.png`, `after-tablet.png`, `after-empty-desktop.png`, `after-failed-mobile.png`, `after-connection-error.png`. 화면 내 추출값은 테스트 응답이며 실제 인식 결과가 아니다.

독립 시각 검증에서 낮은 보조 글자 대비를 발견해 색상 토큰을 조정했다. 최종 보조 텍스트 대비 4.67–5.49:1, 번호 강조색 5.04–5.34:1, 입력 안내문도 보조 글자 토큰 사용. 해당 P2 해소 및 검토 범위 내 잔여 P1/P2 없음. 일반 보조 문구는 최소12px로 보완했다. 이 수치는 해당 색상 조합의 계산 결과이며 전체 WCAG 인증을 의미하지 않는다.

최초 관찰 5개는 모두 수정·관찰 완료. 실제 OCR/저장 설정은 기존 외부 의존성으로 남는다.

## 배포 상태

- 구현 커밋: `6460e93`.
- `vercel deploy --prod --yes` 실행 요청은 자동 승인 검토에서 거절되어 실행되지 않았다. 사유는 외부 Vercel 소스 전송 및 운영 사이트 갱신의 구체적 승인 부족이다.
- 사용자에게 기존 `s07-receipt-organizer` 프로젝트와 공개 URL을 명시해 배포 승인을 요청했다. 우회 배포하지 않았다.
- 로컬 미리보기: http://127.0.0.1:3070 (실제 API 환경 미설정 안내 포함). 공개 사이트에는 이번 UI 변경이 아직 반영되지 않았다.
