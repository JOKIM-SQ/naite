# S07 카테고리 대시보드 전환

사용자 결정: 구매 품목을 제거하고 AI가 쇼핑·장보기·외식·그 외로 분류한다. 기존 로그인·원본·수정 기록을 보존하면서 사이드바, KPI, 월별·카테고리별 지출, 편집·삭제 가능한 영수증 카드로 전환한다.

1. 완료 — API 값 계약과 AI 분류, 전체 기록 조회, 삭제 예약·원본 정리·DB 삭제 및 계정 격리 테스트.
2. 완료 — 이전 주차 스타일을 참고한 반응형 대시보드, 카드, 편집·삭제 대화상자와 로그인·업로드 흐름.
3. 완료 — 실제 저장값만 사용하는 통계 함수와 기간·카테고리·통화 분리 검증. 서로 다른 통화는 환산 없이 합산하지 않는다.
4. 완료 — 타입·구문·134개 회귀 테스트·빌드 검사, 실제 브라우저 데스크톱·모바일 시나리오, 독립 검토와 수정 확인.
5. 완료 — 검증된 구현과 문서, 화면 증거를 같은 변경 묶음으로 기록.
6. 외부 설정 대기 — Supabase SQL 실행 토큰을 사용할 수 없어 사용자에게 SUPABASE-DELETE-MIGRATION.sql 적용 요청. 적용 후 공개 배포와 운영 삭제·실제 분류 확인.

카테고리가 없는 기존 영수증은 원본을 수정하지 않고 ‘그 외’로 표시하며 사용자가 바꿀 수 있다. 기존 개인 영수증과 API 키는 저장소에 추가하지 않는다. 테스트용 OCR과 실제 모델 인식률은 구분한다. 검증 근거는 evidence/dashboard-review.md.
