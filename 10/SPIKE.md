# S10 갈피 — 검증 기록

날짜: 2026-10-15. 가이드: https://initialb.vercel.app/guide.html#s10

## 선택과 범위

사용자가 Fuse.js와 예시 사내 문서·FAQ 20개를 선택했다. Node ESM·정적 HTML/CSS/JavaScript를 사용하고, Fuse.js 7.5.0을 실제 검색 경로에 연결했다. 브라우저 import map은 빌드 시 복사한 `public/vendor/fuse.mjs`를 사용한다. MIT 라이선스도 함께 복사한다. 로그인·DB·필터·AI 응답·문서 관리 기능은 구현하지 않았다. 예시임을 헤더·푸터·문서 내용에 표시한다.

공식 문서는 Context7의 `/krisk/fuse`와 설치 패키지의 타입 선언으로 확인했다. 참고: https://github.com/krisk/fuse 및 https://www.fusejs.io/api/options.html . 제목·키워드·요약·본문에 가중치를 주고 Fuse의 실제 점수로 정렬한다. 검색어·정답 ID에 따른 결과 분기는 없다.

## 한국어 처리에서 막힌 지점

1. 음절 단위 비교에서는 `연챠`, `비밀번오` 등의 오타가 불리해 공백·기호 정리와 Hangul NFD 자모 분해를 사용했다.
2. 처음의 고정 개발 평가 36개는 통과했지만, 별도로 고정한 사용 질의 10개 중 `연챠는 어디서 신청해요?`, `비밀번호를 잊어버렸어요`, `비용정산`, `노트북이 고장났어요`가 빈 결과였다. 핵심 명사와 서술형 어절을 모두 요구한 것이 원인이었다. 제한적인 조사·어미 정리와 문서 키워드 어휘에 근거한 붙임 명사 분리로 보완했다. 문서·질의·기대 문서 ID는 바꾸지 않았다.

전문 형태소 분석이나 의미 검색이 아니다. `연차 쓰고 싶어요`는 현재 빈 결과인 한계를 독립 리뷰에서 재현했다. 개발 평가의 성공률을 모든 한국어 질문의 정확도로 일반화하지 않는다. 붙임 명사는 등록된 문서 키워드 범위에서만 분리한다.

## 실제 브라우저

gstack `$B` 전용 탭에서 `http://127.0.0.1:3100/`을 실행했다. 문서 20개·입력 1개·필터 없음, 실제 Fuse 모듈 로딩과 검색 결과·본문 일치를 확인했다.

- 추가 질의 10개 모두 실제 UI 이벤트를 거쳐 정답이 top3에 표시됐다.
- 다른 결과 선택 시 원문과 선택 표시가 함께 바뀐다. 결과가 없으면 이전 원문을 지운다.
- IME 조합 이벤트 시뮬레이션에서 조합 중에는 결과를 보존하고 확정 후 검색한다. 실제 OS 한글 입력기를 통한 입력 전체를 검증했다는 의미는 아니다.
- 실제 키 입력 ArrowDown→Enter로 두 번째 문서와 포커스가 일치했다. `/`는 검색창 포커스, Escape는 검색 초기화와 전체 20문서 복귀를 확인했다.
- 검색 중 큰 소개 영역을 접어 검색 입력 상단 151px·첫 결과 상단 307px로 표시했다(1280×720). 초기에는 책 일러스트가 있는 소개 화면을 유지한다.
- 1280×720 및 375×812에서 가로 넘침 없음. 작은 화면은 기본 레이아웃만 확인했다.
- 악의적인 검색 문자열이 HTML로 삽입되지 않음을 확인했다. 콘솔 오류 없음.

근거: `10/.qa/flow-result.json`, `galpi-initial.png`, `galpi-search.png`, 저장소 루트 `.omo/evidence/s10-root-checks-20261015.json`, `s10-search-20261015.md`, `s10-ui-20261015.md`, `s10-code-review.md`.

최종 기획서·리포트를 실제 로컬 HTTP로 확인했다. `/docs/plan.html`, `/docs/report.html` 모두 HTTP 200이며 S10·Fuse.js 7.5.0·59/59 검사와 활용형 검색 한계를 포함한다. 팀 템플릿의 태그·CSS·data-f·TSV 스크립트 보존 검사도 통과했다. 공개 배포 URL은 아직 없으므로 리포트의 주소를 만들어 넣지 않았다. 근거: `.qa/docs-result.json`.

## 측정·운영 상태

- 첫 데이터 저장까지 걸린 셋업 시간·공개 배포 시간·공개 로딩 시간·월 비용: 기록 없음.
- 라이브러리: MIT 오픈소스. 현재 검색은 브라우저에서 실행해 별도 검색 서버를 사용하지 않는다.
- 문서 품질: 상. 공식 API와 타입 선언으로 실제 옵션·모듈 경로를 확인할 수 있었다.
- AI 기여도: 상. 데이터·검색·UI·검증 구현에 사용했다.
- 적합도: 잘 맞음. 20개 내외의 고정 문서를 가볍게 검색할 때 사용하겠다. 큰 사내 문서 집합·권한 분리·형태소/의미 검색이 필요하면 이 결과를 그대로 확대 적용하지 않겠다.
- 공개 배포·initialB 등록은 실행하지 않았다. 로컬에서 검토 가능한 완성본과 정해진 경로의 제출 문서를 준비했다.
