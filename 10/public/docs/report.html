예시 20개와 소규모 로컬 텍스트 문서를 검색하는 경우에는 이걸 쓰겠다. 기존 36개·추가 사용 10개·새 자연어 12개 개발 질의가 모두 정답 top 3이며 새 12개는 모두 1위다. 전체 102/102 테스트와 실제 브라우저 원문 강조·관련 문단 이동·파일 추가·개별 실패·중복·새로고침 복원을 확인했다. 공개 주소에서도 새 자연어 12개 정답 1위와 Markdown 추가·새로고침 복원·중복 제외를 확인했다. 일반 한국어 정확도·모든 브라우저 성능을 보장하지 않는다. 공개 배포 완료·initialB 등록 준비 완료, 실제 등록 미실행이다. 1.50분은 새 공개 프로젝트 생성부터 검증용 파일 첫 보관 관찰까지 90초이며 기존 로컬 개발 셋업·총 개발 시간은 미측정이다. 0.67분은 최초 배포 READY 관찰까지 40초로 관찰 오버헤드를 포함한다. 0.096초는 QA Chromium 첫 공개 navigation load 95.8ms이며 다기기·완전 cold cache·상호작용 준비 시간 보장이 아니다. 이 값들은 첫 공개 검증 실측이며 후속 문서 배포 시간이 아니다.
