01누가 쓰나

입사 초기 구성원. 연차·비용·재택 같은 업무 절차를 찾지만 문서의 정확한 제목을 모른다. 실제 사용 빈도는 기록 없음.

02지금은

문서 목록에서 제목을 훑고 여러 본문을 열어 필요한 안내를 찾는다. 현재 탐색 시간은 기록 없음.

03없앨 동작 하나

정확한 제목을 찾으려고 관련 문서를 하나씩 열어 보는 동작.

04핵심 기능 1개

자연스러운 한국어 질의를 Fuse.js로 검색하고 선택 본문의 실제 원문을 강조해 관련 문단으로 이동한다. 예시 20개는 유지하며 TXT·MD·Markdown 선택/드롭으로 내 문서를 추가하고 새로고침 후 복원한다.

05안 만드는 것 3개

  • 로그인·서버 DB·문서 편집·삭제
  • 검색 필터·관리자·설정 화면
  • AI 답변 생성·챗봇·외부 웹 검색

06성공 판정

  • 예시 20개·검색창 1개·필터 없음. 기존 36개·추가 사용 10개·새 자연어 12개 개발 질의가 모두 정답 top 3이며 새 12개는 모두 1위다. 전체 102/102 테스트를 통과했다. 실제 브라우저 파일 추가·개별 실패·중복·새로고침 복원·긴 문서 관련 문단 이동을 확인했다. 일반 한국어 정확도 벤치마크는 아니다.

07내 옵션 + 이유

Fuse.js 7.5.0에 제한적 한국어 표현·업무 동의어 보완을 더한다. UTF-8 파일은 서버 전송 없이 같은 브라우저·출처의 IndexedDB에 보관한다. 파일당 256KiB·배치 10개·내 문서 100개·총 5MiB, 같은 내용은 중복 제외다. 기기 동기화·전문 형태소 분석·AI 의미 검색은 없다.

08리스크 + 검증법

걱정되는 것: 한국어 표현 차이가 검색 순위·원문 강조에 미치는 영향과 큰 문서 검색 비용·브라우저 보관 제약.
화요일 스파이크로 확인: 기존 추가 질의 4개 실패를 보완한 뒤 업무 동의어와 질문형 처리를 확장해 ‘연차 쓰고 싶어요’도 검색된다. UTF-16 원문 좌표·실제 문단 이동과 저장 커밋 후 성공·실패 시 기존 자료 보존을 검증했다. 일반 정확도·모든 브라우저 성능을 보장하지 않는다. 실측은 SPIKE.md에 기록했다.
