# S10 갈피 기획

사내 문서의 정확한 제목을 모르는 구성원이 검색어 하나로 필요한 안내를 찾는다. 승인된 예시 문서·FAQ 20개를 대상으로 하는 정적 검색 MVP다.

## 문제와 핵심 동작

사용자는 연차 신청·재택 신청 같은 절차를 찾으려고 문서를 하나씩 열어 읽는다. 현재 탐색 시간은 기록 없음이다. 갈피는 검색 입력 → Fuse.js 순위 결과 → 선택한 본문 확인으로 이 탐색을 줄인다.

아이보리 배경과 세이지 강조색, 책갈피를 모티프로 한다. 검색창은 하나이며 필터가 없다. 결과 목록과 문서 본문을 함께 보고 좁은 화면에서는 읽기 순서를 유지한다.

## 확정 데이터와 구현

예시 문서 주제는 연차, 비용, 재택, 비밀번호, 온보딩, 출장, 회의실, 보안, 장비, 복지, 급여, 건강검진, 소프트웨어, 릴리스, 코드 리뷰, 장애, 문서 작성, 권한, 초과근무, 퇴사다. 모두 연습용 예시이며 실제 회사 정책을 주장하지 않는다.

Fuse.js 7.5.0을 실제 검색에 사용한다. HTML/CSS/ESM 정적 앱으로 구현하며 브라우저 import map이 빌드한 vendor 파일을 읽는다. Node 검증도 같은 설치 패키지를 사용한다. 한국어 정규화·공백 처리·제한된 표현 보완은 허용하되, 전문 형태소 분석기와 의미 검색은 도입하지 않는다.

## 안 만드는 것 3개

1. 로그인, DB 연결, 문서 추가·수정·삭제.
2. 검색 필터, 관리자 화면, 설정 기능.
3. AI 답변 생성, 챗봇, 외부 웹 검색.

## 성공 판정과 검증

| 시나리오 | 이진 판정 | 검증 방법 |
| --- | --- | --- |
| 예시 데이터 | 서로 다른 문서 20개가 모두 존재 | Node 데이터 검사 |
| 오타 검색 | 고정 평가 세트의 정답 문서가 상위 3개에 포함 | `npm run evaluate`, 검색 테스트 |
| 검색·선택 흐름 | 입력한 질의의 결과와 선택 문서 본문이 연결 | DOM 검사 및 실제 브라우저 QA |
| 빈 입력·결과 없음 | 오류 없이 안내하고 이전 본문이 잘못 남지 않음 | DOM 검사 및 실제 브라우저 QA |
| 단일 검색창 | 검색 입력 1개, 필터 없음 | UI 구조 검사 및 실제 브라우저 QA |
| 제출 문서 | 템플릿 태그·CSS·data-f·복사 스크립트 보존 | 원본과 구조 비교 |

자동 검사 순서는 `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`다. 통과 수·실행 환경·증거는 SPIKE.md에 기록한다. 평가 세트를 구현에 맞춰 바꾸거나 질의별 정답 순위를 하드코딩하지 않는다.

## 리스크와 데모 주제

핵심 리스크는 한국어 음절 오타·띄어쓰기·다른 표현이 문자열 유사도에 미치는 영향이다. 같은 고정 질의로 원본 Fuse.js와 최소 보완 후의 상위 3개를 비교한다. 데모에서는 **한국어 처리에서 막힌 지점** 한 가지와 실제 검색 결과를 보여준다. 모든 한국어 표현이나 사내 문서 규모에 대한 일반화는 하지 않는다.

가이드: [S10 사내 지식 검색](https://initialb.vercel.app/guide.html#s10). 배포 주소·실제 제출 결과는 SUBMISSION.md에서 별도로 관리한다.

## 최종 확인 — 2026-10-15

문서 20개와 검색창 1개·필터 없음이 확인됐다. 고정 검색 평가는 정상 27/27·오타 9/9로 정답 top 3를 충족했다. 이후 실행 전에 정한 추가 사용 질의 10개 중 4개가 처음 실패했고, 조사·어미 정리와 문서 키워드 어휘 기반 붙임 명사 분리로 보완해 10/10을 통과했다. 개발 평가 결과이며 일반 한국어 정확도를 뜻하지 않는다.

전체 테스트 59/59, 타입·린트·빌드와 독립 코드 리뷰 CLEAR/APPROVE를 확인했다. 실제 브라우저에서도 추가 질의 10개 top 3, 선택 본문, 결과 없음·초기화, 키보드, 1280×720·375×812의 가로 넘침 없음을 확인했다. IME는 이벤트 시뮬레이션까지만 검증했다. `연차 쓰고 싶어요`는 여전히 빈 결과다. 상세 근거는 SPIKE.md에 있으며 공개 배포·initialB 등록은 실행하지 않았다.
