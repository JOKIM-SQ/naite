# S10 갈피 기획

문서의 정확한 제목을 모르는 구성원이 검색어 하나로 필요한 안내를 찾는다. 승인된 예시 문서·FAQ 20개와 사용자가 브라우저에 추가한 텍스트 문서를 대상으로 하는 정적 검색 MVP다.

## 문제와 핵심 동작

사용자는 연차 신청·재택 신청 같은 절차를 찾으려고 문서를 하나씩 열어 읽는다. 현재 탐색 시간은 기록 없음이다. 갈피는 검색 입력 → Fuse.js 순위 결과 → 원문 강조 → 관련 문단 보기로 이 탐색을 줄인다. `연차 쓰고 싶어요`, `비번 까먹었어` 같은 제한된 자연어 표현과 업무 동의어도 처리한다.

아이보리 배경과 세이지 강조색, 책갈피를 모티프로 한다. 검색창은 하나이며 필터가 없다. 결과 목록과 문서 본문을 함께 보고 좁은 화면에서는 읽기 순서를 유지한다. 파일 선택·드롭은 검색 자료를 추가하는 진입점이며 별도 검색창이 아니다.

## 확정 데이터와 구현

예시 문서 주제는 연차, 비용, 재택, 비밀번호, 온보딩, 출장, 회의실, 보안, 장비, 복지, 급여, 건강검진, 소프트웨어, 릴리스, 코드 리뷰, 장애, 문서 작성, 권한, 초과근무, 퇴사다. 예시 20개는 그대로 유지하며 실제 회사 정책을 주장하지 않는다.

Fuse.js 7.5.0을 실제 검색에 사용한다. HTML/CSS/ESM 정적 앱으로 구현하며 브라우저 import map이 빌드한 vendor 파일을 읽는다. Node 검증도 같은 설치 패키지를 사용한다. 한국어 정규화·조사/질문형 정리·제한적 업무 어휘 치환을 사용하며 전문 형태소 분석기와 AI 의미 검색은 도입하지 않는다.

강조는 원문 UTF-16 좌표로 표시한다. 관련 부분 보기는 실제 근거가 있는 문단으로 이동한다. 원문에 없는 문구를 만들어 강조하지 않으며 키워드에만 맞으면 본문 근거가 없을 수 있다.

## 승인된 파일 추가 범위

UTF-8 `.txt`·`.md`·`.markdown` 파일을 선택하거나 드롭한다. 파일당 256KiB, 한 번에 10개, 내 문서 최대 100개, 원본 총 5MiB까지다. 내장 예시와 내 문서를 구분하고 내 문서만 IndexedDB에 보관해 새로고침 후 복원한다. 파일은 서버에 전송하지 않으며 같은 브라우저·같은 출처(origin)에 한정된다. 다른 기기 동기화는 없다.

내용 SHA-256이 같으면 다른 파일명도 중복으로 건너뛴다. 지원하지 않는 파일 등 개별 실패를 알리고 정상 파일은 추가한다. 성공 표시는 트랜잭션 커밋 이후이며 실패해도 기존 자료와 검색어를 유지한다. 추가 중 다시 들어온 요청은 완료 후 재시도하도록 안내한다. Markdown은 텍스트 기반 제목·섹션을 읽으며 HTML을 실행하지 않는다.

## 안 만드는 것 3개

1. 로그인, 서버 DB 연결, 문서 편집·삭제.
2. 검색 필터, 관리자 화면, 설정 기능.
3. AI 답변 생성, 챗봇, 외부 웹 검색.

| 예시 데이터 | 서로 다른 예시 문서 20개 유지, 내 문서와 구분 | Node 데이터 검사·브라우저 표시 |

| 단일 검색창 | 검색 입력 1개, 필터 없음 | UI 구조 검사 및 브라우저 QA |

자동 검사 순서는 `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`다. 통과 수·실행 환경·증거는 SPIKE.md에 기록한다. 평가 세트를 구현에 맞춰 바꾸거나 질의별 정답 순위를 하드코딩하지 않는다.

## 리스크와 데모 주제

핵심 리스크는 한국어 음절 오타·띄어쓰기·다른 표현이 문자열 유사도에 미치는 영향이다. 데모에서는 **한국어 처리에서 막힌 지점** 한 가지와 실제 검색·원문 근거를 보여준다. 취소 정책이 없는 문서 모음에서는 관련 키워드 문서가 나올 수 있으며 정책 답변을 보장하지 않는다. 큰 문서에서 동기 검색 비용이 남고 브라우저 저장소 정리·출처 변경 시 보관 자료를 사용할 수 없을 수 있다.

가이드: [S10 사내 지식 검색](https://initialb.vercel.app/guide.html#s10). 배포 주소·실제 제출 결과는 SUBMISSION.md에서 별도로 관리한다.

## 최종 확인 — 2026-10-15

전체 102/102 테스트(검색 74·DOM 15·보관 모듈 11·HTTP 2), 타입·린트·빌드와 독립 코드 리뷰 CLEAR/APPROVE를 확인했다. 개발 질의는 기존 정상 27·오타 9, 추가 사용 10, 새 자연어 12로 총 58개가 정답 top 3를 충족했다. 새 12개는 모두 1위다. 이전에 빈 결과였던 `연차 쓰고 싶어요`도 연차 문서를 찾는다. 개발·회귀 평가이며 일반 한국어 정확도 벤치마크가 아니다.

실제 브라우저에서도 새 자연어 12개 모두 정답 1위와 `연차`만 강조되는 결과를 확인했다. MD/TXT 2개 추가와 잘못된 CSV 개별 안내, 입력 질의 보존, 새로고침 후 예시 20개·내 문서 2개 복원, 동일 파일 중복 건너뛰기를 확인했다. 긴 TXT 드롭 후 31번째 문단의 검색어를 강조하고 관련 부분 보기로 읽기 영역이 이동하며 페이지와 검색창 위치는 유지됐다. 기존 검색·선택·키보드 검증을 유지하며 IME는 조합 이벤트 시뮬레이션 범위다. 상세 근거는 SPIKE.md에 있다. [공개 앱](https://s10-galpi.vercel.app/) 배포를 완료했으며 initialB 등록 준비 완료·실제 등록 미실행 상태다.

공개 주소의 보관함과 로컬 주소의 보관함은 출처가 달라 별개이며 로컬 파일을 자동 전송하지 않는다. 첫 공개 프로젝트 생성부터 검증용 파일 첫 보관 관찰까지 1.50분, 첫 배포 READY 관찰까지 0.67분, QA Chromium 첫 공개 navigation load 0.096초를 측정했다. 기존 로컬 개발 셋업 시간과 후속 문서 배포 시간으로 해석하지 않는다. 다기기·완전 cold cache·상호작용 준비 시간 측정은 아니며 상세 조건은 SUBMISSION.md에 기록했다.

공개 주소에서도 새 자연어 12개 모두 정답 1위, 원문 강조, 검증용 Markdown 1개 보관·새로고침 후 예시20+내1=21개 복원·중복 0개 추가를 확인했다. 자격 증명 없는 공개 GET 8개는 모두 HTTP 200이며 앱 자산 SHA-256이 로컬 소스와 일치했다. 근거는 `.qa/public-flow-result.json`과 `.qa/public-duplicate.json`이다.
