## 완료한 로컬 검증

- 예시 문서 20개, 검색창 1개·필터 없음, 고정 평가 정상 27/27·오타 9/9의 정답 top 3를 확인했습니다.
- 추가 사용 질의 10개를 실행 전에 정했으며 최초 4개 실패 후 일반 검색 전처리를 보완해 10/10을 통과했습니다. 고정 개발 평가이며 일반 한국어 정확도가 아닙니다.
- 타입·린트·빌드 및 전체 59/59 테스트가 통과했습니다. 구성은 검색 41개·추가 사용 질의 10개·DOM 6개·실제 HTTP 2개입니다.
- 실제 브라우저 추가 질의 10개 top 3, 선택 본문, 결과 없음·초기화, 방향키·Enter·`/`·Escape를 확인했습니다. IME는 조합 이벤트 시뮬레이션으로 확인했으며 실제 OS 입력기 전체 검증은 아닙니다.
- 1280×720·375×812에서 가로 넘침이 없고 콘솔 오류가 없었습니다. 검색 중 소개 영역이 접혀 1280×720의 입력 상단 151px·첫 결과 상단 307px로 표시됐습니다.
- 독립 리뷰 CLEAR/APPROVE입니다. `연차 쓰고 싶어요`가 빈 결과인 한계는 재현했고 숨기지 않았습니다.

근거는 SPIKE.md, `.qa/flow-result.json`, `.qa/galpi-initial.png`, `.qa/galpi-search.png`와 저장소 루트 `.omo/evidence/s10-root-checks-20261015.json`, `s10-root-20261015.md`, `s10-code-review.md`입니다. 개발 평가와 회귀 테스트의 질의가 겹치므로 독립 벤치마크로 합산하지 않습니다.

## 공개 제출 전 남은 항목

- 공개 배포 후 앱·`/docs/plan.html`·`/docs/report.html` 주소가 열리는지 확인합니다.
- 배포가 확인되면 리포트 `data-f="url"`의 텍스트·href를 실제 주소로 갱신합니다. 현재 href는 빈 값이며 로컬 주소를 공개 주소로 제출하지 않습니다.
- 첫 저장까지의 셋업 시간, 공개 배포 시간·첫 로딩, 실제 운영 비용은 기록 없음입니다. 템플릿 minutes는 숫자 형식을 요구하지만 측정치가 없어 기록 없음으로 남겼습니다. 0분으로 오인하지 않습니다.
- 문서 품질 상·AI 기여 상·적합도 잘 맞음으로 기록했습니다. 근거는 공식 API·타입 선언 확인, 구현에 AI 사용, 20개 고정 문서 범위의 실측입니다. Fuse.js는 MIT 오픈소스이며 별도 검색 서버를 사용하지 않습니다.
- initialB 실제 등록은 별도 명시적 게시 요청이 있을 때 진행합니다. 현재 복사 버튼이 있다는 이유로 제출 완료를 주장하지 않습니다.

## 3분 데모 순서

1. 로컬 또는 확인된 공개 주소를 엽니다.
2. 검색창에 `연차`를 입력하고 결과를 선택합니다.
3. `연챠 신청`을 입력하고 연차 문서를 선택합니다.
4. `비밀번오 초기화`를 입력하고 비밀번호 문서를 선택한 뒤 Escape를 누릅니다.
5. 스택 리포트를 엽니다.

발표 주제는 **한국어 처리에서 막힌 지점**입니다. 음절 오타를 위한 NFD 분해와, 추가 사용 질의 4개 실패 후 제한적인 조사·어미 정리 및 키워드 기반 붙임 명사 분리로 보완한 과정을 설명합니다. 전문 형태소 분석·의미 검색은 아니며 `연차 쓰고 싶어요`는 빈 결과입니다. 시연 소요 시간은 기록 없음입니다.

안 만든 것 3개는 로그인·DB·문서 CRUD / 필터·관리 기능 / AI 생성·챗봇·외부 검색입니다. 예시 20개는 사용자 승인 데이터이며 실제 회사 정책이 아닙니다.
