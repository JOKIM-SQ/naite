승인된 검색·원문 근거·로컬 파일 추가 확장을 포함한 로컬 완성본과 기획서·스택 리포트를 준비했습니다. 공개 배포·initialB 등록은 실행하지 않았습니다.

## 완료한 로컬 검증

- 예시 20개 유지와 내 문서 구분, 검색창 1개·필터 없음입니다. 숨긴 파일 선택기는 검색창이 아닙니다.
- 기존 개발 평가 정상 27·오타 9, 추가 사용 10, 새 자연어 12의 총 58개가 정답 top 3입니다. 새 12개는 모두 1위이며 `연차 쓰고 싶어요`도 정상 검색됩니다. 일반 한국어 정확도 벤치마크가 아닙니다.
- 타입·린트·빌드 및 전체 102/102 테스트가 통과했습니다. 구성은 검색 74·DOM 15·보관 모듈 11·HTTP 2입니다. 동시 구현 중의 실패 로그와 구분한 최종 순차 검사 결과입니다.
- 실제 브라우저에서 MD/TXT 2개 추가·잘못된 CSV 개별 안내·기존 `오로라` 질의 보존을 확인했습니다. 새로고침 후 예시 20개·내 문서 2개가 복원됐고 같은 파일 재선택은 0개 추가·총 22개를 유지했습니다.
- 긴 TXT 드롭 후 31번째 마지막 문단의 `달빛자료`가 강조됐습니다. 관련 부분 보기에서 읽기 영역 scrollTop이 0→4350으로 이동하고 페이지 scrollY 0과 검색창 위치를 유지했습니다.
- 최종 실제 브라우저 자연어 12개 모두 정답 1위, `연차`만 강조(잘못된 `연락` 강조 없음), 이모지 제목 강조·NFD 입력·원문 HTML 문자 표시·결과 없음/초기화·검색창 1개/파일 선택기 1개·가로 넘침 없음을 확인했습니다.
- 기존 실제 브라우저 검색·선택·결과 없음·초기화·방향키·Enter·`/`·Escape 검증을 유지합니다. IME는 조합 이벤트 시뮬레이션이며 실제 OS 입력기 전체 검증은 아닙니다.
- 독립 리뷰 CLEAR/APPROVE입니다. `연차` 질의의 잘못된 `연락` 강조를 수정하고 원문 근거 회귀를 통과했습니다. 약 3.88MB·20문서의 Node 독립 단일 관측은 정확 검색 138ms·오타 검색 231ms이며 모든 브라우저 성능을 보장하는 수치가 아닙니다.

근거는 SPIKE.md, `.qa/extension-upload.json`, `.qa/extension-restored.json`, `.qa/extension-duplicate.json`, `.qa/extension-drop-long-before.json`, `.qa/extension-drop-long-after.json`, `.qa/extension-final-flow.json`, `.qa/galpi-evidence-import-final.png` 및 저장소 루트 `.omo/evidence/s10-extension-checks-final-20261015.json`, `s10-natural-evidence-20261015.md`, `s10-library-20261015.md`, `s10-enhanced-ui-20261015.md`, `s10-extension-code-review.md`입니다. 개발 평가와 회귀 테스트의 질의가 겹치므로 독립 벤치마크로 합산하지 않습니다.

## 파일 보관과 범위

UTF-8 TXT/MD/Markdown 파일을 선택·드롭하고 IndexedDB에 보관합니다. 파일당 256KiB·배치 10개·내 문서 100개·원본 총 5MiB 한도입니다. 같은 내용 SHA-256이면 다른 이름도 중복입니다. 파일별 실패를 알리고 저장 커밋 이후 성공으로 처리하며 실패 시 기존 자료·질의를 유지합니다. 동시 추가는 완료 후 재시도하도록 안내합니다.

파일은 서버에 전송하지 않으며 같은 브라우저·같은 출처(origin)에서만 복원됩니다. 다른 기기 동기화가 아니며 브라우저 저장소 정리 시 자료를 잃을 수 있습니다. 안 만든 것 3개는 로그인·서버 DB·문서 편집/삭제 / 필터·관리 기능 / AI 생성·챗봇·외부 검색입니다. 예시 20개는 실제 회사 정책이 아닙니다.

## 공개 제출 전 남은 항목

- 공개 배포 후 앱·`/docs/plan.html`·`/docs/report.html` 주소가 열리는지 확인합니다.
- 배포가 확인되면 리포트 `data-f="url"`의 텍스트·href를 실제 주소로 갱신합니다. 현재 href는 빈 값이며 로컬 주소를 공개 주소로 제출하지 않습니다.
- 첫 저장까지의 셋업 시간, 공개 배포 시간·첫 로딩, 실제 운영 비용은 기록 없음입니다. 템플릿 minutes는 숫자 형식을 요구하지만 측정치가 없어 기록 없음으로 남겼습니다. 0분으로 오인하지 않습니다.
- 문서 품질 상·AI 기여 상·적합도 잘 맞음으로 기록했습니다. 근거는 공식 API·타입 선언 확인, 구현에 AI 사용, 소규모 예시·추가 문서의 개발 검증입니다. Fuse.js는 MIT 오픈소스이며 별도 검색 서버를 사용하지 않습니다.
- initialB 실제 등록은 별도 명시적 게시 요청이 있을 때 진행합니다. 복사 버튼만으로 제출 완료를 주장하지 않습니다.

## 3분 데모 순서

1. 앱에서 `연차 쓰고 싶어요`를 입력하고 연차 문서를 선택합니다.
2. `비번 까먹었어`를 입력하고 강조된 원문과 ‘관련 부분 보기’를 누릅니다.
3. UTF-8 TXT 또는 MD 파일을 추가하고 해당 파일의 검색어를 입력합니다.
4. 새로고침하고 같은 검색어로 내 문서를 다시 찾습니다.
5. 스택 리포트를 엽니다.

발표 주제는 **한국어 처리에서 막힌 지점**입니다. 음절 오타를 위한 NFD 분해, 조사·질문형 정리와 제한적 업무 동의어 보완, 실제 원문 근거를 설명합니다. 전문 형태소 분석·AI 의미 검색은 아닙니다. 시연 소요 시간은 기록 없음입니다.
