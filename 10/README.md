# 갈피 · Galpi

검색어 하나로 예시 사내 문서·FAQ 20개를 찾는 S10 검색 MVP입니다. Fuse.js가 순위를 계산하고 선택한 결과의 본문을 함께 표시합니다. 문서는 모두 연습용 예시이며 실제 회사 규정이 아닙니다.

## 실행

Node.js 22 이상에서 `10/`을 작업 폴더로 사용합니다.

```sh
npm ci
npm run dev
```

앱은 [http://127.0.0.1:3100](http://127.0.0.1:3100)에서 엽니다. 기획서는 `/docs/plan.html`, 스택 리포트는 `/docs/report.html`에 있습니다.

검색창에 `연차`, `재택`, `비밀번호` 같은 단어를 입력하고 결과를 선택해 본문을 읽습니다. `연챠 신청`, `비밀번오 초기화`도 검증된 오타 질의입니다. `/`로 검색창에 포커스하고 방향키·Enter로 결과를 선택하거나 Escape로 초기화할 수 있습니다.

## 검사와 빌드

```sh
npx tsc --noEmit
npm run lint
npm test
npm run evaluate
npm run build
```

테스트는 Node 내장 테스트 러너와 linkedom을 사용합니다. TypeScript는 `checkJs`로 JavaScript를 검사합니다. 빌드는 설치된 Fuse.js 7.5.0의 브라우저 모듈을 `public/vendor`로 복사하며 배포 출력은 `public/`입니다. 브라우저의 bare import는 HTML import map을 통해 해당 vendor 모듈로 연결됩니다. 실행에 로그인·API 키·DB 설정은 필요하지 않습니다.

## 범위와 한계

- 문서 20개는 연차·비용·재택·보안·개발 업무 등을 다루는 승인된 예시 데이터입니다.
- 검색창 하나와 결과 목록·본문만 제공합니다. 필터, 로그인, 문서 편집, 관리자 기능은 없습니다.
- Fuse.js 기반 문자열 유사도 검색입니다. 한국어 최소 보완은 전문 형태소 분석이나 의미 검색이 아닙니다.
- AI 답변·챗봇·외부 검색을 제공하지 않습니다.
- 고정 평가 세트의 통과 여부는 모든 질의에 대한 정확도를 보장하지 않습니다.
- `연차 쓰고 싶어요`는 현재 빈 결과입니다. 자연어 의미를 해석하는 검색은 아닙니다.

## 확인한 결과

2026-10-15 타입·린트·빌드와 전체 테스트 59/59가 통과했습니다. 고정 검색 평가는 정상 27/27·오타 9/9로 총 36/36 정답 top 3, 별도 사용 질의는 10/10입니다. 추가 질의 10개는 실행 전에 정했고 최초 4개 실패 후 일반적인 한국어 전처리를 보완했습니다. 이 수치는 개발·회귀 평가이며 서로 독립된 정확도 벤치마크가 아닙니다.

실제 브라우저에서 추가 질의 10개와 선택 본문, 결과 없음·초기화, 방향키·Enter·`/`·Escape를 확인했습니다. 검색 중 소개 영역을 접으며 1280×720·375×812에서 가로 넘침과 콘솔 오류가 없었습니다. IME 조합 이벤트는 시뮬레이션했으며 실제 OS 한글 입력기 전체 검증은 아닙니다. 독립 코드 리뷰는 CLEAR/APPROVE입니다.

Fuse.js는 MIT 오픈소스이며 이 앱은 별도 검색 서버를 사용하지 않습니다. 실제 운영 비용·셋업 시간·공개 배포 및 공개 로딩 시간은 기록 없음입니다.

검증 수치와 브라우저 확인 결과는 [SPIKE.md](SPIKE.md), 기획 범위는 [PLAN.md](PLAN.md), 배포·제출 상태는 [SUBMISSION.md](SUBMISSION.md)에 기록합니다. 현재 공개 배포 주소는 기록 없음입니다.
