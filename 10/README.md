# 갈피 · Galpi

검색어 하나로 예시 사내 문서·FAQ 20개와 직접 추가한 텍스트 문서를 찾는 S10 검색 MVP입니다. Fuse.js가 순위를 계산하고 원문 강조와 관련 문단 보기를 제공합니다. 예시 문서는 연습용이며 실제 회사 규정이 아닙니다.

공개 앱: [https://s10-galpi.vercel.app/](https://s10-galpi.vercel.app/) · [기획서](https://s10-galpi.vercel.app/docs/plan.html) · [스택 리포트](https://s10-galpi.vercel.app/docs/report.html)

## 로컬 실행

Node.js 22 이상에서 `10/`을 작업 폴더로 사용합니다.

```sh
npm ci
npm run dev
```

앱은 [http://127.0.0.1:3100](http://127.0.0.1:3100)에서 엽니다. 기획서는 `/docs/plan.html`, 스택 리포트는 `/docs/report.html`에 있습니다.

검색창에 `연차 쓰고 싶어요`, `비번 까먹었어`, `집에서 일하고 싶어요`를 입력하고 결과를 선택해 본문을 읽습니다. `연챠 신청`, `비밀번오 초기화`도 검증된 오타 질의입니다. 본문의 강조 부분을 보거나 ‘관련 부분 보기’로 해당 문단으로 이동합니다. `/`로 검색창에 포커스하고 방향키·Enter로 결과를 선택하거나 Escape로 초기화할 수 있습니다.

## 내 문서 추가

‘문서 추가’에서 파일을 선택하거나 안내 영역에 드롭합니다. UTF-8 `.txt`·`.md`·`.markdown`을 지원하며 파일당 256KiB, 한 번에 10개, 내 문서 최대 100개·원본 총 5MiB까지입니다. 예시 20개는 유지되고 추가 자료는 ‘내 문서’로 구분됩니다.

파일은 서버에 보내지 않고 IndexedDB에 보관하며 같은 브라우저·같은 주소 출처(origin)에서 새로고침 후 복원합니다. 다른 브라우저나 기기로 동기화하지 않습니다. 로컬 `127.0.0.1:3100`과 공개 주소는 출처가 달라 보관함이 별개이며 로컬 파일을 공개 사이트로 자동 전송하지 않습니다. 브라우저 사이트 데이터 삭제나 출처 변경 시 기존 보관함을 사용할 수 없을 수 있습니다.

내용 SHA-256이 같으면 이름이 달라도 중복으로 건너뜁니다. 지원하지 않는 형식·용량 초과 등은 파일별로 알리고 정상 파일은 추가합니다. 트랜잭션 저장 완료 뒤 검색에 반영하며 실패 시 기존 자료와 검색어를 유지합니다. 추가 중인 경우 완료 뒤 다시 시도하세요. Markdown은 텍스트 제목·섹션을 읽으며 HTML 실행·외부 링크 가져오기는 하지 않습니다. 원본 파일 백업·내보내기와 문서 편집·삭제는 제공하지 않습니다.

## 검사와 빌드

```sh
npx tsc --noEmit
npm run lint
npm test
npm run evaluate
npm run build
```

테스트는 Node 내장 테스트 러너, linkedom, fake-indexeddb를 사용합니다. TypeScript는 `checkJs`로 JavaScript를 검사합니다. 빌드는 설치된 Fuse.js 7.5.0의 브라우저 모듈을 `public/vendor`로 복사하며 배포 출력은 `public/`입니다. 브라우저의 bare import는 HTML import map을 통해 해당 vendor 모듈로 연결됩니다. 실행에 로그인·API 키·서버 DB 설정은 필요하지 않습니다.

## 범위와 한계

- 검색창 하나와 결과 목록·본문, 로컬 파일 추가를 제공합니다. 필터, 로그인, 문서 편집·삭제, 관리자 기능은 없습니다.
- Fuse.js 기반 문자열 유사도 검색에 제한적 한국어 표현 정리와 업무 동의어를 더했습니다. 전문 형태소 분석이나 AI 의미 검색이 아닙니다.
- 강조는 원문 UTF-16 좌표에 해당하는 실제 텍스트입니다. 키워드에만 맞으면 본문 강조가 없을 수 있습니다.
- AI 답변·챗봇·외부 검색을 제공하지 않습니다. 취소 정책 등 자료에 없는 답변은 보장하지 않습니다.
- 고정 개발 질의의 통과는 모든 질의의 정확도를 보장하지 않습니다. 동기 검색 비용과 브라우저 저장 공간 제약도 남습니다.

## 확인한 결과

2026-10-15 타입·린트·빌드와 전체 102/102 테스트가 통과했습니다(검색 74·DOM 15·보관 모듈 11·HTTP 2). 기존 고정 질의 정상 27·오타 9, 추가 사용 질의 10, 새 자연어 질의 12의 총 58개에서 정답 top 3를 확인했습니다. 새 12개는 모두 1위이며 `연차 쓰고 싶어요`의 이전 빈 결과는 해결했습니다. 개발·회귀 평가이며 서로 독립된 정확도 벤치마크가 아닙니다.

실제 브라우저에서도 새 자연어 12개 모두 정답 1위와 `연차`만 강조되는 결과를 확인했습니다. MD/TXT 2개 추가, 잘못된 CSV의 개별 실패 안내, 입력 질의 유지, 새로고침 후 예시 20개·내 문서 2개 복원, 중복 건너뛰기를 확인했습니다. 긴 TXT를 드롭한 뒤 마지막 31번째 문단의 검색어 강조·관련 문단 이동도 확인했고 페이지와 검색창 위치는 유지됐습니다. 이모지가 포함된 제목 강조, NFD 입력, 원문 HTML의 문자 표시, 결과 없음·초기화, 검색창 1개·파일 선택기 1개와 가로 넘침 없음도 확인했습니다. 기존 검색·선택·키보드 검증을 유지합니다. IME는 조합 이벤트 시뮬레이션이며 실제 OS 한글 입력기 전체 검증은 아닙니다. 독립 코드 리뷰는 CLEAR/APPROVE입니다.

Fuse.js는 MIT 오픈소스이며 별도 검색 서버를 사용하지 않습니다. 실제 운영 비용과 기존 로컬 개발 셋업 시간은 기록 없음입니다. 첫 공개 프로젝트 생성부터 검증용 파일 첫 보관 관찰까지 1.50분, 첫 배포 READY 관찰까지 0.67분, QA Chromium 첫 공개 navigation load 0.096초를 측정했습니다. 이 값은 최초 공개 검증의 관측값이며 총 개발 시간·후속 문서 배포 시간·모든 기기의 성능이 아닙니다. 측정 시각과 조건은 SUBMISSION.md에 기록했습니다.

검증 수치와 브라우저 확인 결과는 [SPIKE.md](SPIKE.md), 기획 범위는 [PLAN.md](PLAN.md), 배포·제출 상태는 [SUBMISSION.md](SUBMISSION.md)에 기록합니다. 공개 배포 완료·initialB 등록 준비 완료 상태이며 실제 등록은 실행하지 않았습니다.

공개 주소에서도 새 자연어 12개 모두 정답 1위, 올바른 원문 강조, 검증용 Markdown 1개 보관·새로고침 후 21개 복원·동일 파일 중복 제외를 확인했습니다. 자격 증명 없는 앱·자산 GET 8개는 모두 HTTP 200이며 소스 SHA-256도 일치했습니다. 공개 검증 근거는 `.qa/public-flow-result.json`, `.qa/public-duplicate.json`입니다.
