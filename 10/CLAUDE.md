# S10 갈피 (Galpi)

이 폴더의 현재 과제는 **사내 지식 검색**이다. 상위 CLAUDE.md의 S07 영수증·OCR·인증 지시는 이번 과제에 적용하지 않는다. 작업 범위는 같은 저장소의 `10/`이다.

- 핵심 기능: 검색창 하나에 입력 → Fuse.js 검색 → 순위별 결과 → 선택한 문서 본문 확인.
- 사용자 확정 스택: Fuse.js 7.5.0, vanilla HTML/CSS/ESM. 실제 검색 경로에 Fuse.js를 사용한다.
- 데이터: 사용자 승인 예시 사내 문서·FAQ 20개. 실제 회사 규정이나 연결된 사내 데이터가 아니다.
- 성공 조건: 문서 20개를 검색하고 고정 평가 세트의 오타 질의에서 정답이 상위 3개에 포함된다. 수치는 실행 증거가 있을 때만 기록한다.
- 화면: 아이보리·세이지의 책갈피 컨셉, 단일 검색 입력, 순위 결과 목록, 선택 본문의 분할 화면. 검색 필터는 없다.
- 제외: 로그인·DB·문서 CRUD / 필터·관리 기능 / AI 생성·챗봇·외부 검색.
- 한국어 보완은 정규화·공백·최소 표현 수준으로 제한한다. 전문 형태소 분석이나 의미 검색으로 설명하지 않는다.

Node 내장 테스트, TypeScript `checkJs`, linkedom으로 필요한 검증을 한다. `npm run dev`의 로컬 주소는 `http://127.0.0.1:3100`이다. `npm run build`는 브라우저용 Fuse.js 파일을 `public/vendor`로 복사하며, HTML import map은 Node 테스트와 같은 설치 패키지를 연결한다.

팀 기획서·리포트는 `_template/public/docs/` 원본의 태그 구조·CSS·data-f·TSV 스크립트를 보존한다. 모르는 소요 시간·한도·배포 URL·평가는 `기록 없음`으로 남긴다. 실제 배포 및 initialB 등록 여부를 준비 상태와 구분한다.

범위와 검증 기준은 [PLAN.md](PLAN.md), 실행법은 [README.md](README.md), 제출 상태와 데모 순서는 [SUBMISSION.md](SUBMISSION.md), 실제 실험 기록은 [SPIKE.md](SPIKE.md)를 따른다. 공유 작업 공간의 다른 작업자 변경을 되돌리지 않는다.
