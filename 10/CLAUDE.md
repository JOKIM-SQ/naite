# S10 갈피 (Galpi)

이 폴더의 현재 과제는 **사내 지식 검색**이다. 상위 CLAUDE.md의 S07 영수증·OCR·인증 지시는 이번 과제에 적용하지 않는다. 작업 범위는 같은 저장소의 `10/`이다.

- 핵심 기능: 검색창 하나에 입력 → Fuse.js 순위 결과 → 원문 강조와 관련 문단 확인.
- 사용자 확정 스택: Fuse.js 7.5.0, vanilla HTML/CSS/ESM. 실제 검색 경로에 Fuse.js를 사용한다.
- 데이터: 사용자 승인 예시 사내 문서·FAQ 20개를 그대로 유지하고 추가한 파일은 ‘내 문서’로 구분한다. 예시는 실제 회사 규정이 아니다.
- 승인된 확장: 자연스러운 한국어 질의와 제한적 업무 동의어, 원문 UTF-16 좌표에 따른 강조·관련 부분 보기, TXT/MD/Markdown 파일 선택·드롭 및 IndexedDB 보관·새로고침 복원.
- 파일 조건: UTF-8 `.txt`·`.md`·`.markdown`, 파일당 256KiB·배치 10개·내 문서 최대 100개·원본 총 5MiB. 내용 SHA-256이 같으면 이름이 달라도 중복으로 건너뛴다.
- 저장: 파일을 서버에 보내지 않고 같은 브라우저·같은 출처(origin)에 보관한다. 다른 기기 동기화가 아니다. 트랜잭션 커밋 후 성공으로 처리하며 파일별 실패를 안내한다. 실패 때 기존 자료·검색어를 유지하고 동시 추가는 완료 뒤 다시 시도하도록 안내한다.
- 화면: 아이보리·세이지의 책갈피 컨셉, 단일 검색 입력, 순위 결과 목록, 선택 본문의 분할 화면. 별도 숨긴 파일 선택기는 검색창이 아니다.
- 제외: 로그인·서버 DB·문서 편집/삭제 / 검색 필터·관리 기능 / AI 생성·챗봇·외부 검색.
- 한국어 보완은 제한적 정규화·조사/질문형 정리·업무 어휘 치환이다. 전문 형태소 분석이나 AI 의미 검색으로 설명하지 않는다.

Node 내장 테스트, TypeScript `checkJs`, linkedom, fake-indexeddb로 필요한 검증을 한다. `npm run dev`의 로컬 주소는 `http://127.0.0.1:3100`이다. `npm run build`는 브라우저용 Fuse.js 파일을 `public/vendor`로 복사하며, HTML import map은 Node 테스트와 같은 설치 패키지를 연결한다.

팀 기획서·리포트는 `_template/public/docs/` 원본의 태그 구조·CSS·data-f·TSV 스크립트를 보존한다. 모르는 소요 시간·배포 URL·평가는 `기록 없음`으로 남긴다. 실제 배포 및 initialB 등록 여부를 준비 상태와 구분한다.

범위와 검증 기준은 [PLAN.md](PLAN.md), 실행법은 [README.md](README.md), 제출 상태와 데모 순서는 [SUBMISSION.md](SUBMISSION.md), 실제 실험 기록은 [SPIKE.md](SPIKE.md)를 따른다. 공유 작업 공간의 다른 작업자 변경을 되돌리지 않는다.

2026-10-15 확장 최종 자동 검사: 타입·린트·빌드와 전체 102/102 테스트 통과(검색 74·DOM 15·보관 모듈 11·HTTP 2). 개발 질의는 기존 36개·추가 사용 10개·새 자연어 12개 모두 정답 top 3이며 새 12개는 모두 1위다. `연차 쓰고 싶어요`의 이전 빈 결과는 해결됐다. 실제 브라우저에서도 새 자연어 12개 모두 정답 1위, 연차 원문 강조, 파일 추가·부분 실패·중복·새로고침 복원·긴 문서 관련 문단 이동을 확인했다. IME는 조합 이벤트 시뮬레이션이다. 일반 한국어 정확도·모든 브라우저 성능을 보장하지 않는다. 독립 리뷰 CLEAR/APPROVE. 공개 배포 완료: https://s10-galpi.vercel.app/ — initialB 등록 준비 완료, 실제 등록 미실행.

공개 보관함은 로컬 `127.0.0.1:3100`과 출처가 달라 별개다. 로컬 파일을 공개 사이트로 자동 전송하지 않는다. 첫 공개 프로젝트 생성부터 검증용 파일 첫 보관 관찰까지 1.50분, 최초 배포 READY 관찰까지 0.67분, QA Chromium 첫 공개 navigation load 0.096초다. 기존 로컬 개발 셋업·총 개발 시간은 미측정이며 이 값은 후속 문서 배포 시간이 아니다. 정확한 시각·방법·한계는 SUBMISSION.md와 SPIKE.md를 따른다.

공개 주소에서도 새 자연어 12개 모두 정답 1위, 원문 강조, 검증용 Markdown 1개 보관·새로고침 후 예시20+내1=21개 복원·중복 0개 추가를 확인했다. 자격 증명 없는 공개 GET 8개는 모두 HTTP 200이며 앱 자산 SHA-256이 로컬 소스와 일치했다. 근거는 `.qa/public-flow-result.json`과 `.qa/public-duplicate.json`이다.
