02지금은

담당자가 문의마다 분류와 초안 작성을 직접 시작한다. 기존 처리 시간과 절감 시간은 기록 없음.

03없앨 동작 하나

문의를 접수한 뒤 담당자가 분류와 답변 초안 작성을 매번 직접 시작하는 동작.

04핵심 기능 1개

문의 접수에는 바로 응답하고, Inngest가 나중에 분류와 답변 초안을 생성해 실제 처리 단계·재시도·검토 필요 여부와 함께 보여준다.

05안 만드는 것 3개

  • 회원가입·로그인과 팀 권한 관리
  • 외부 메일함 연결과 문의 자동 수집
  • 답변 자동 발송 및 고객에게 보내기

06성공 판정

  • 2026-10-23 실제 Supabase·Inngest·Claude에서 일반 문의 분류·초안, 복합 문의 검토 필요, 첫 실패 후 2회차 자동 복구, 3회 실패 후 수동 재접수의 정상 완료를 확인했다. 작업공간 분리도 확인했으며 공개 배포·갤러리 등록은 아직 실행하지 않았다.

07내 옵션 + 이유

Inngest로 접수 요청과 AI 작업을 분리하고, 단계별 처리와 실패 재시도를 코드로 추적한다. Next.js 화면, 기존 Supabase의 S11 전용 저장소, AI SDK를 통한 Claude를 연결한다. 실제 정상 AI 처리와 재시도·최종 실패·수동 복구를 확인했다. 4개 합성 시나리오의 결과이며 일반 정확도·성능 평가로 확대하지 않는다.
